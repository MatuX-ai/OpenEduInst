## 前端技术栈

| 技术 | 版本 | 用途 | 选型理由 |
|------|------|------|---------|
| Angular | 17+ | 前端框架 | TypeScript 原生支持，成熟的企业级生态，适合大型教育管理系统 |
| TypeScript | 5.x | 开发语言 | 类型安全，减少运行时错误，提升可维护性 |
| PrimeNG | 17+ | UI 组件库 | 丰富的企业级组件（表格、日历、图表），文档完善 |
| Angular Router | 17+ | 路由管理 | 原生集成，支持懒加载 |
| Signals / NgRx | - | 状态管理 | Angular 17 原生 Signals + 可选 NgRx 处理复杂状态 |
| ECharts | 5.x | 图表组件 | 丰富的中文图表能力，适合统计报表和仪表盘 |
| RxJS | 7.x | 响应式编程 | Angular 原生集成，处理异步数据流 |
| Vite | 5.x | 构建工具 | 快速的开发服务器和构建 |

## 后端技术栈

| 技术 | 版本 | 用途 | 选型理由 |
|------|------|------|---------|
| Python | 3.11+ | 开发语言 | 数据处理生态丰富，开发效率高，教育领域广泛使用 |
| FastAPI | 0.110+ | Web 框架 | 高性能异步支持，自动生成 OpenAPI 文档，类型安全 |
| Uvicorn | 0.27+ | ASGI 服务器 | 高性能异步 Web 服务器，FastAPI 官方推荐 |
| SQLAlchemy | 2.0+ | ORM | 功能强大的 ORM，支持异步，多租户 Schema 管理灵活 |
| Alembic | 1.13+ | 数据库迁移 | SQLAlchemy 官方迁移工具，支持版本化 Schema 变更 |
| Pydantic | 2.x | 数据验证 | FastAPI 原生集成，自动请求验证和响应序列化 |
| PyJWT | 2.8+ | JWT 认证 | 轻量、成熟的 JWT 实现 |
| bcrypt | 4.1+ | 密码哈希 | 行业标准的密码安全算法 |

## 数据库与存储

| 技术 | 版本 | 用途 | 选型理由 |
|------|------|------|---------|
| PostgreSQL | 15+ | 主数据库 | 强大的 Schema 隔离支持，JSONB 数据类型，适合多租户架构 |
| Redis | 7+ | 缓存与消息 | 高性能缓存、会话管理、速率限制、Pub/Sub 消息队列 |
| 对象存储 (可选) | S3 兼容 | 文件存储 | 备份文件、用户上传文件的存储，兼容阿里云 OSS、AWS S3 |
