## 整体开发路线图

### v1.0 - MVP 版本 (开源社区版)

**目标**: 完成核心教育培训管理功能

| 阶段 | 功能模块 | 预计周期 |
|------|---------|----------|
| Phase 1 | 用户与角色管理、机构管理、学员管理 | 4 周 |
| Phase 2 | 课程与班级管理、排课与考勤 | 4 周 |
| Phase 3 | 财务订单管理、数据统计报表 | 3 周 |
| Phase 4 | 测试、部署准备、文档完善 | 2 周 |

### v2.0 - 云托管版增强

**目标**: 增加 AI 助手、资源集成、多端同步等高级功能

| 阶段 | 功能模块 | 预计周期 |
|------|---------|----------|
| Phase 1 | 云自动备份与一键回滚 | 2 周 |
| Phase 2 | AI 教学助手集成 | 4 周 |
| Phase 3 | 多租户架构与许可证管理 | 3 周 |
| Phase 4 | OpenSciEd STEM 资源集成 | 3 周 |
| Phase 5 | WebSocket 多端实时同步 | 2 周 |
| Phase 6 | 企业级安全与审计日志 | 2 周 |

## 技术栈

### 前端
- **框架**: Angular 17+
- **UI 组件库**: PrimeNG / Material
- **状态管理**: NgRx / Signals
- **图表**: ECharts
- **构建工具**: Vite

### 后端
- **框架**: FastAPI (Python 3.11+)
- **数据库**: PostgreSQL 15+
- **缓存与消息**: Redis 7
- **ORM**: SQLAlchemy 2.0 + Alembic
- **认证**: JWT (PyJWT)
- **AI 集成**: OpenAI API / Claude API (按版本启用)

### 部署
- **容器化**: Docker + Docker Compose
- **反向代理**: Nginx
- **备份**: pg_dump + 对象存储
- **监控**: 可选 Prometheus + Grafana
