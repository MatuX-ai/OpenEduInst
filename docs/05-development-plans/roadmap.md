## 版本发布策略

### 版本号规范

```
主版本号 . 次版本号 . 修订号
│            │          │
│            │          └──  bug 修复、小功能优化
│            │
│            └──  新功能模块、API 扩展
│
└──  架构变更、不兼容更新、重大功能升级
```

### 发布频率

| 类型 | 频率 | 说明 |
|------|------|------|
| 主版本 (X.0.0) | 6-12 个月 | 重大架构变更或核心功能升级 |
| 次版本 (x.X.0) | 2-3 个月 | 新功能模块上线 |
| 修订版 (x.x.X) | 2 周 | Bug 修复和小优化 |

## v1.0 开源社区版里程碑

### M1: 基础用户与机构管理 (Week 1-4)

**功能清单**:
- 机构信息管理 (创建、编辑、查看)
- 用户账户管理 (注册、登录、密码重置)
- 角色权限系统 (admin, operator, teacher, finance, parent)
- JWT Token 认证与刷新机制
- 个人资料与偏好设置

**技术要点**:
- 完成 RBAC 权限中间件
- 实现密码安全策略 (bcrypt, 强度要求)
- 前端用户界面: 登录页、用户管理页

### M2: 学员与课程管理 (Week 5-8)

**功能清单**:
- 学员档案 (添加、编辑、搜索、导入)
- 课程管理 (创建课程、分类、定价)
- 班级管理 (开班、分配教师、班级学员)
- 学员报名与转班流程

**技术要点**:
- 完成分页列表组件与通用表单组件
- 实现 Excel 导入导出功能
- 前端数据表格支持排序、过滤

### M3: 排课与考勤 (Week 9-12)

**功能清单**:
- 日历视图排课 (月视图、周视图、日视图)
- 课时安排与冲突检测
- 出勤标记 (出勤、缺勤、迟到、请假)
- 考勤统计与报表

**技术要点**:
- 实现日历组件
- 设计排课冲突检测算法
- 前端拖拽排课功能

### M4: 财务与数据统计 (Week 13-15)

**功能清单**:
- 订单管理 (创建订单、记录付款)
- 退款处理
- 收入统计图表 (按日、月、课程)
- 学员人数、出勤率统计仪表盘

**技术要点**:
- 集成 ECharts 图表组件
- 设计数据统计的聚合查询

### M5: 测试、部署、文档 (Week 16-17)

**功能清单**:
- 端到端功能测试
- 部署文档编写
- Docker 容器化
- API 文档生成 (Swagger/OpenAPI)

**交付物**:
- v1.0.0 GitHub Release
- Docker Image
- 部署指南与用户手册

## v2.0 云托管增强版里程碑

### C1: 数据备份与恢复 (Week 1-2)

- 自动每日备份
- 手动备份触发
- 备份列表与恢复流程
- 备份文件管理

### C2: AI 教学助手 (Week 3-6)

- AI 对话界面 (类 ChatGPT)
- 课程设计辅助
- 课堂活动建议
- 教学资源推荐
- Token 用量统计与配额管理

### C3: 多租户架构 (Week 7-9)

- PostgreSQL Schema 隔离
- 许可证管理系统 (试用/标准/企业版)
- 资源配额管理
- 机构资源使用监控

### C4: OpenSciEd 资源集成 (Week 10-12)

- API 代理服务
- 资源中心前端界面
- 按主题、年级搜索
- 资源使用统计

### C5: WebSocket 实时同步 (Week 13-14)

- 实时排课同步
- 实时考勤通知
- 多终端数据同步
- 断线重连机制

### C6: 企业级安全 (Week 15-16)

- 操作审计日志
- 安全事件监控
- 敏感数据加密存储
- 速率限制与防暴力破解

## 功能优先级矩阵

| 优先级 | 定义 | 示例功能 |
|--------|------|---------|
| P0 (Critical) | 发布前必须完成 | 用户认证、学员管理、课程管理 |
| P1 (High) | 核心功能，本版本内完成 | 排课考勤、财务订单、数据统计 |
| P2 (Medium) | 本版本可选，但重要 | 高级报表、自定义字段 |
| P3 (Low) | 后续版本考虑 | 移动端 App、消息推送 |
