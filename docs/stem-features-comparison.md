# OpenMT vs 普通教培系统 - STEM 特色功能对比

## 🎯 核心定位差异

| 维度 | 普通教培系统（如 MatuX） | OpenMT（STEM 教育专属） |
|------|------------------------|------------------------|
| **目标用户** | 培训机构、K12 学校 | K12科创中心、职业学校实训基地、编程培训机构、教育局监管平台 |
| **核心价值** | 招生、排课、消课、营收 | **硬件管理、实验项目、创客空间、Token计费** |
| **业务场景** | 文化课培训、兴趣班 | **机器人编程、物联网应用、3D打印、科学实验** |
| **数据重点** | 学员数、消课率、续费率 | **设备使用率、项目完成率、竞赛获奖数、硬件损耗** |

### 4. 创客空间调度（⭐ STEM 核心特色）

#### 普通教培系统
- ❌ 无此功能
- 或者仅有"教室预约"（时间段 + 教室号）

#### OpenMT
✅ **创客空间调度**
- **实验室预约系统**
  - 时间段选择（上午/下午/晚上，每段 2 小时）
  - 设备配置（预约时指定需要的设备：3D 打印机 x2、Arduino x10）

  - 培训认证（学生需通过"激光切割机安全操作"考试）

  - 跨班级借用（A 班的 Arduino 可以借给 B 班）

  - 谁在何时使用了什么设备（张老师 2024-05-20 14:00-16:00 使用 3D 打印机）
  - 设备状态记录（使用前正常 → 使用后故障 → 报修）
  - 耗材使用量（3D 打印消耗 filament 200g）

## 🎨 UI/UX 设计建议

### 视觉风格
- **主色调**：科技蓝（#0066FF）+ 电路板绿（#00CC66）
- **辅助色**：橙色（#FF6600，用于警告/强调）
- **背景**：深色模式优先（符合程序员/工程师审美）
- **图标**：使用 Lucide React 的科技类图标（cpu、circuit-board、robot、code）

### 文案风格
- **避免**："提升教学质量"、"优化管理流程"（过于泛泛）
- **推荐**："让每个学生都能亲手打造智能硬件"、"从 Arduino 到 IoT，一站式管理创客教育"

### 交互细节
- **硬件借出流程**：扫码动画 + 音效反馈（"滴"声）
- **项目提交**：进度条动画 + 庆祝效果（confetti）
- **Token 消耗**：实时余额更新 + 预警提示（红色闪烁）

## 📝 总结

### OpenMT 的核心竞争力

1. **专注 STEM 教育**：不是通用教培系统，而是为科创教育量身定制
2. **硬件管理闭环**：从采购、租赁、维护到报废的全生命周期管理
3. **教具耗材管理**：耗材库存预警、领用追踪、申购审批全流程覆盖
4. **项目驱动学习**：支持机器人竞赛、创客作品、编程项目的完整流程
5. **学生作品社区**：作品展示、互动社交、精选推荐，激发创作热情
6. **AI 赋能教学**：Token 计费系统让 AI 助教、智能评测触手可及
7. **开源透明**：代码可审计、数据隐私保护、无厂商锁定

### 与普通教培系统的本质区别

| 普通教培 | OpenMT |
|---------|--------|
| 卖的是"课时" | 卖的是"创造体验" |
| 关注"学了什么" | 关注"做出了什么" |
| 标准化课程 | 个性化项目 |
| 被动听课 | 主动探索 |
| 纸笔考试 | 实物作品 |

**一句话定位**：  
**OpenMT 不是另一个排课系统，而是 STEM 教育的操作系统。**
