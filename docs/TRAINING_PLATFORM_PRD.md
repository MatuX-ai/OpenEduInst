# OpenMTEduInst 培训机构管理系统 - 产品需求文档（PRD）

## 1. 文档概述

### 1.1 产品定位
面向STEM培训机构的SaaS管理平台，覆盖招生、教学、财务、运营全流程，突出竞赛认证、项目管理、资源库等STEM特色功能。

### 1.2 目标用户
- **机构负责人**：查看经营数据、管理多校区、决策分析
- **教务主管**：排课管理、教师调度、学员档案维护
- **授课教师**：课堂反馈、学员评价、课时统计
- **招生顾问**：线索跟进、活动推广、转化分析
- **家长/学员**：查看学习进度、课堂反馈、续费报名

### 1.3 核心价值
1. **业务闭环**：招生→教学→消课→续费全流程数字化
2. **STEM特色**：竞赛报名、项目管理、教学资源库差异化优势
3. **数据驱动**：续费率、转化率、教师绩效等关键指标可视化
4. **多校区扩展**：总部-分校统一管控，资源灵活调配

## 2. 功能模块详细说明

### 2.1 运营概览（Dashboard）

#### 功能描述
机构经营数据总览，核心KPI实时监控。

#### 页面元素
- **KPI卡片**：在训学员、本月营收、消课率、设备使用率
- **营收趋势图**：近6个月课程费/设备租赁/Token充值对比
- **快捷操作**：快速报名、设备借出、签到打卡、新建项目
- **最近动态**：设备采购、项目评审、Token充值等操作日志

#### 业务规则
- KPI数据实时计算，缓存5分钟
- 营收趋势支持按月/季度切换
- 动态按时间倒序排列，最多显示20条

---

### 2.2 学员管理

#### 功能描述
学员档案管理、课时追踪、续费提醒。

#### 页面元素
- **学员列表**：姓名、年级、报读课程、剩余课时、状态
- **筛选条件**：在读/即将到期/已结课、课程类型、年级
- **学员详情**：成长档案、项目作品、荣誉记录、上课记录

#### 业务规则
- **剩余课时预警**：≤10课时标记为"即将到期"
- **续费率计算**：(续费人数 / 到期人数) × 100%
- **批量操作**：支持Excel导入/导出学员信息

#### 数据字段
```
student_id (主键)
name (姓名)
grade (年级)
phone (联系电话)
parent_name (家长姓名)
enroll_date (入学日期)
status (在读/即将到期/已结课)
courses (关联课程ID列表)
total_hours (总课时)
remaining_hours (剩余课时)
achievements (荣誉记录JSON)
```

---

### 2.3 招生线索

#### 功能描述
潜在客户管理、转化漏斗分析、试听课预约。

#### 页面元素
- **线索列表**：家长姓名、电话、来源渠道、意向课程、跟进状态
- **转化漏斗**：地推/老带新/线上/转介绍各渠道转化率
- **快捷操作**：安排试听、批量外呼、导入线索

#### 业务规则
- **线索状态流转**：待跟进 → 已预约试听 → 已报名 / 未接通
- **转化率计算**：(报名人数 / 线索总数) × 100%
- **跟进提醒**：创建后24小时内未跟进标红预警

#### 数据字段
```
lead_id (主键)
parent_name (家长姓名)
phone (联系电话)
source (来源渠道：地推/老带新/线上/转介绍)
interest_course (意向课程)
student_grade (学员年级)
status (待跟进/已预约/已报名/未接通)
create_time (创建时间)
follow_up_time (下次跟进时间)
assigned_to (负责顾问ID)
```

---

### 2.4 智能排课

#### 功能描述
课程表管理、教室资源调度、教师排班冲突检测。

#### 页面元素
- **今日课表**：时间、课程名称、教室、教师、学员数
- **周视图/月视图**：日历形式展示
- **冲突检测**：教师/教室时间重叠预警

#### 业务规则
- **排课约束**：同一教师同一时间只能上一节课
- **教室容量**：学员数不能超过教室最大容量
- **调课流程**：申请→审批→通知家长

---

### 2.5 设备资产

#### 功能描述
硬件设备库存管理、借用记录、维护保养。

#### 页面元素
- **设备清单**：Arduino/Raspberry Pi/传感器/3D打印机等
- **库存状态**：总量、可借出、使用中、待维护
- **借用记录**：哪个班级/学生借用、借出时间、归还时间

#### 业务规则
- **低库存预警**：可借出≤5台标黄提醒
- **维护计划**：定期校准/耗材更换提醒
- **损耗统计**：按月统计设备损坏率

---

### 2.6 项目管理

#### 功能描述
STEM项目全生命周期管理，从立项到成果展示。

#### 页面元素
- **项目列表**：项目名称、类别（IoT/AI/机器人）、进度、状态
- **里程碑追踪**：硬件搭建→传感器调试→控制逻辑→系统集成→展示
- **技术栈标签**：Arduino/Python/ESP32/OpenCV等

#### 业务规则
- **项目状态**：规划中 → 进行中 → 已完成
- **进度计算**：(已完成里程碑数 / 总里程碑数) × 100%
- **成果归档**：项目完成后自动归入学员作品集

#### 数据字段
```
project_id (主键)
name (项目名称)
category (类别：IoT/AI/机器人)
instructor_id (指导教师ID)
students (参与学员ID列表)
start_date (开始日期)
end_date (结束日期)
status (规划中/进行中/已完成)
progress (进度百分比)
milestones (里程碑JSON数组)
technologies (技术栈标签数组)
```

---

### 2.7 教学资源库

#### 功能描述
课件、代码、视频等教学资源共享平台。

#### 页面元素
- **分类浏览**：Arduino课件库、Python编程、机器人课程、IoT项目
- **资源卡片**：名称、类型（PPT/PDF/视频/代码）、大小、下载次数
- **上传功能**：拖拽上传、格式校验、分类选择

#### 业务规则
- **权限控制**：教师可上传，学员仅下载
- **下载统计**：记录每次下载，生成热门资源排行
- **版本管理**：同一资源支持多版本（V1.0/V2.0）

---

### 2.8 竞赛认证

#### 功能描述
白名单赛事报名、等级考试安排、获奖成果管理。

#### 页面元素
- **赛事列表**：电子学会大赛、蓝桥杯、世界机器人大会等
- **报名管理**：参赛学员、报名截止、比赛日期
- **等级认证**：Python考级、Arduino认证、AI水平测试

#### 业务规则
- **权威赛事**：仅展示教育部/行业协会白名单赛事
- **报名截止提醒**：截止前7天/3天/1天推送通知
- **获奖归档**：自动同步到学员荣誉墙

#### 数据字段
```
competition_id (主键)
name (赛事名称)
organizer (主办方：中国电子学会/工信部等)
level (级别：国家级/省级/国际级)
category (类别：机器人/编程/创客)
register_deadline (报名截止)
competition_date (比赛日期)
participants (参赛学员ID列表)
status (报名中/筹备中/已截止/已结束)
```

---

### 2.9 营销中心

#### 功能描述
拼团活动、优惠券配置、招生推广工具。

#### 页面元素
- **活动管理**：春季招生拼团、老带新推荐、暑期集训营早鸟价
- **优惠券列表**：新人专享券、续费优惠券、拼团专属券
- **转化分析**：各活动参与人数、转化率、带来营收

#### 业务规则
- **拼团规则**：3人成团，每人优惠¥200
- **优惠券有效期**：设置起止时间，过期自动失效
- **使用限制**：满减条件、适用课程、每人限用次数

---

### 2.10 Token中心

#### 功能描述
AI助教、智能评测、课程生成等AI功能的Token计费管理。

#### 页面元素
- **余额显示**：当前Token余额、充值记录
- **消耗分布**：AI助教/智能评测/课程生成/代码审查占比
- **充值套餐**：5000点/10000点/20000点档位

#### 业务规则
- **扣费逻辑**：每次调用AI功能按用量扣费
- **低余额预警**：余额<1000点推送提醒
- **成本分摊**：按班级/项目统计Token消耗

---

### 2.11 财务结算

#### 功能描述
课时费结算、教师工资、营收分析、账单管理。

#### 页面元素
- **营收趋势**：课程费/设备租赁/Token充值构成
- **待确认账单**：学员消课记录、金额、确认状态
- **教师工资**：授课时长×单价、待发放列表

#### 业务规则
- **课时费计算**：不同级别教师不同单价（高级¥150/h、中级¥120/h、初级¥100/h）
- **账单确认**：教务确认后触发家长端缴费通知
- **工资发放**：批量确认后打款到教师账户

---

### 2.12 教师绩效

#### 功能描述
授课时长统计、学员评价、续费率排行。

#### 页面元素
- **绩效排行**：授课时长、评分、续费率、满意度、月营收
- **授课趋势图**：近6个月各教师课时对比
- **评价详情**：学员/家长评分、文字评价

#### 业务规则
- **评分计算**：课后即时评价，取平均值
- **续费率统计**：该教师所教学员的续费比例
- **绩效等级**：S/A/B/C四档，与奖金挂钩

---

### 2.13 家长中心

#### 功能描述
学员成长档案、课堂反馈、家校互动。

#### 页面元素
- **学员信息**：头像、年级、在学课程、综合评分
- **课程进度**：学习进度条、剩余课时、下次上课时间
- **课堂反馈**：教师评语、课后作业、课堂照片
- **荣誉墙**：获奖证书、等级认证、优秀学员

#### 业务规则
- **反馈推送**：每次课后2小时内推送给家长
- **作业提交**：家长可上传学员作品照片
- **续费入口**：剩余课时<10时显示续费按钮

---

### 2.14 多校区管理

#### 功能描述
总部-分校统一管控，数据汇总、资源调配。

#### 页面元素
- **校区列表**：名称、地址、负责人、学员数、营收、续费率
- **营收对比图**：各校区月度营收柱状图
- **资源分配**：Arduino套件/树莓派/3D打印机等设备分布

#### 业务规则
- **数据隔离**：各校区数据独立，总部可查看汇总
- **资源调拨**：总部可向分校调配设备，记录调拨日志
- **统一账号**：教师可在多个校区授课

---

### 2.15 消息中心

#### 功能描述
审批提醒、续费预警、活动通知统一管理。

#### 页面元素
- **消息分类**：审批提醒、续费预警、活动通知、系统通知
- **优先级标识**：紧急/高/中/低
- **快捷操作**：一键已读、跳转处理

#### 业务规则
- **推送规则**：
  - 审批类：立即推送
  - 续费预警：每周一上午9点汇总推送
  - 活动通知：活动开始前7天/3天/1天推送
- **未读数 Badge**：侧边栏显示未读消息数

## 4. 业务流程图

### 4.1 招生转化流程
```
线索录入 → 分配顾问 → 电话跟进 → 预约试听 → 试听课 → 报名缴费 → 分班排课
     ↓              ↓           ↓           ↓
   未接通        跟进超时    爽约       未通过
```

### 4.2 消课结算流程
```
学员签到 → 扣除课时 → 生成账单 → 教务确认 → 家长缴费 → 教师课时费结算
```

### 4.3 竞赛报名流程
```
发布赛事 → 学员报名 → 资格审核 → 缴费确认 → 赛前培训 → 参赛 → 获奖归档
```

## 5. 非功能性需求

### 5.1 性能要求
- 页面加载时间 < 2秒
- API响应时间 < 500ms
- 支持并发用户数 ≥ 500

### 5.2 安全要求
- 数据传输HTTPS加密
- 敏感信息（电话/身份证）脱敏显示
- RBAC权限控制，防止越权访问

### 5.3 兼容性
- 浏览器：Chrome 90+、Safari 14+、Edge 90+
- 移动端：iOS Safari、Android Chrome自适应
