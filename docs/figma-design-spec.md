# OpenMT Demo 网站 - Figma 原型设计规范

## 📋 设计概述

**项目名称**：OpenMT Demo 网站  
**设计风格**：科技感、STEM 教育专属、深色模式优先  
**参考对标**：https://www.matux.tech/institution-dashboard（对比突出差异化）  
**核心差异化**：硬件管理、实验项目、Token 计费、创客空间

## 🎨 视觉设计规范

### 1. 色彩系统

#### 主色调
```
科技蓝（Primary Blue）: #0066FF
- 用于：主要按钮、链接、强调元素
- 变体：
  - Light: #3385FF
  - Dark: #0052CC

电路板绿（Circuit Green）: #00CC66
- 用于：成功状态、STEM 特色标识、进度条
- 变体：
  - Light: #33D985
  - Dark: #00A352
```

#### 辅助色
```
警告橙（Warning Orange）: #FF6600
- 用于：警告提示、Token 余额不足、设备故障

错误红（Error Red）: #FF3333
- 用于：错误提示、删除操作、逾期警告

中性灰（Neutral Gray）:
- Background Dark: #0F172A（深空蓝黑，主背景）
- Background Card: #1E293B（卡片背景）
- Border: #334155（边框）
- Text Primary: #F1F5F9（主要文字）
- Text Secondary: #94A3B8（次要文字）
```

#### 渐变色
```
Hero 背景渐变：
linear-gradient(135deg, #0F172A 0%, #1E293B 50%, #0F172A 100%)

按钮悬停渐变：
linear-gradient(90deg, #0066FF 0%, #00CC66 100%)
```

## 🎬 动画与交互规范

### 1. 页面过渡动画
```
类型：Fade + Slide
持续时间：300ms
缓动函数：ease-in-out

实现：
- Framer Motion（React）
- 进入：opacity 0→1, y 20px→0
- 离开：opacity 1→0, y 0→-20px
```

### 2. 按钮交互
```
默认状态：
- 背景：科技蓝（#0066FF）
- 文字：白色
- 圆角：8px
- 阴影：Shadow Md

悬停状态：
- 背景：渐变（科技蓝 → 电路板绿）
- 上浮：translateY(-2px)
- 阴影：Shadow Lg
- 过渡：200ms

点击状态：
- 缩放：scale(0.98)
- 阴影：Shadow Sm
```

### 3. 卡片悬停效果
```
默认状态：
- 边框：1px solid #334155
- 阴影：Shadow Sm

悬停状态：
- 边框：1px solid #0066FF
- 发光：Glow Blue
- 上浮：translateY(-4px)
- 阴影：Shadow Xl
- 过渡：300ms
```

### 4. 数字滚动动画
```
场景：社会证明区的"500+"
持续时间：2000ms
缓动函数：ease-out

实现：
- 从 0 滚动到 500
- 每 10ms 更新一次
- 添加千位分隔符（500+）
```

### 5. 加载状态

## 🎯 设计检查清单

- [ ] 所有页面使用统一的色彩系统
