## 核心模块测试用例

### 用户与认证模块

| 测试用例 | 预期结果 | 优先级 |
|---------|---------|--------|
| 管理员登录成功 | 成功进入仪表板 | P0 |
| 错误密码登录失败 | 提示密码错误，计数失败次数 | P0 |
| JWT Token 过期后自动刷新 | 使用 refresh_token 重新获取 | P0 |
| 权限不足访问受限页面 | 返回 403 无权限 | P0 |
| 密码强度检测 | 不符合要求的密码被拒绝 | P1 |

## 集成测试场景

| 场景 | 描述 |
|------|------|
| 新学员全流程 | 机构创建 → 添加学员 → 报名课程 → 排课 → 考勤 → 付费 |
| 排课冲突处理 | 尝试为同一教师在同一时间排两门课 |
| 并发操作 | 多用户同时编辑同一学员信息 |
| 数据备份恢复 | 备份 → 修改数据 → 恢复 → 验证数据还原 |

## 性能测试指标

| 指标 | 目标值 | 测试条件 |
|------|--------|---------|
| API 响应时间 | < 500ms | 单用户 |
| API 响应时间 | < 2s | 100 并发用户 |
| 列表页面加载 | < 1s | 1000 条数据 |
| 数据库查询 | < 100ms | 常用查询 |
| 系统支持并发 | >= 100 连接 | 标准版 |
