## 测试策略总览

### 测试层级

```
┌───────────────────────────────────┐
│  E2E 测试 (端到端)                 │
│  - 用户操作全流程                 │
│  - Playwright / Cypress           │
└───────────────────────────────────┘
                │
                ▼
┌───────────────────────────────────┐
│  集成测试 (Integration)           │
│  - API 接口测试                   │
│  - 数据库交互测试                 │
│  - pytest + httpx                │
└───────────────────────────────────┘
                │
                ▼
┌───────────────────────────────────┐
│  单元测试 (Unit)                  │
│  - 函数/类级别测试               │
│  - pytest / Jasmine              │
└───────────────────────────────────┘
```

### 覆盖率目标

| 层级 | 最低覆盖率 | 建议覆盖率 |
|------|-----------|-----------|
| 后端单元测试 | 70% | 85%+ |
| 核心业务模块 | 80% | 90%+ |
| 前端组件测试 | 50% | 70%+ |
| API 集成测试 | 80% | 95%+ |
