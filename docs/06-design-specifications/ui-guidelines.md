## 设计原则

1. **清晰一致**: 所有页面使用统一的布局和组件风格
2. **高效操作**: 支持键盘快捷操作，减少用户点击次数
3. **数据可视**: 关键数据以图表形式呈现，一目了然
4. **安全可靠**: 涉及删除、退款等危险操作需二次确认

## 布局与导航

### 主布局结构

```
┌──────────────────────────────────────────────────────┐
│  Logo      顶部导航 (仪表板/学员/课程/排课/财务/设置)    │
├──────────────┬───────────────────────────────────────┤
│  侧边栏       │                                      │
│  - 仪表板     │            主内容区域                 │
│  - 学员管理   │                                       │
│  - 课程管理   │                                       │
│  - 排课管理   │                                       │
│  - 财务管理   │                                       │
│  - 数据备份   │                                       │
│  - 系统设置   │                                       │
│              │                                       │
└──────────────┴───────────────────────────────────────┘
```

### 响应式断点

| 设备 | 宽度范围 | 布局 |
|------|---------|------|
| 手机 | < 768px | 单栏布局，侧边栏折叠为抽屉 |
| 平板 | 768-1200px | 侧边栏 + 主内容 |
| 桌面 | >= 1200px | 完整多栏布局 |

## 组件使用规范

### 通用组件规范

- 列表页面必须包含: 搜索栏、筛选器、分页器
- 详情页面必须包含: 返回按钮、编辑按钮、操作菜单
- 表单必须包含: 必填标记、实时验证、提交后反馈

### 通用按钮规范

| 操作 | 按钮类型 | 确认方式 |
|------|---------|---------|
| 创建/新增 | Primary | 直接提交 |
| 编辑/修改 | Secondary | 直接提交 |
| 删除 | Danger | 二次确认对话框 |
| 退款 | Warning | 二次确认对话框 |
