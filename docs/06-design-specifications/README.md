## 核心设计原则

### 前端 UI
- **响应式布局**: 适配桌面 (PC)、平板 (Pad)、手机三端
- **统一组件**: 所有列表、表单、对话框使用统一组件库
- **中文友好**: 中文文案优先，时区和日期格式适配国内使用习惯

### 后端 API
- **RESTful 设计**: 使用标准 HTTP 方法，资源作为名词
- **统一响应**: 所有接口返回统一格式的 JSON 响应
- **错误处理**: 统一的错误码和错误信息格式

### 代码规范
- **TypeScript/Angular**: 遵循 Angular Style Guide
- **Python/FastAPI**: 遵循 PEP 8 + FastAPI 最佳实践
- **Git**: 约定式提交 (Conventional Commits)
