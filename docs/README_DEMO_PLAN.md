## 🎯 项目概览

**项目名称**：OpenMT Demo 网站  
**项目目标**：打造专业的 **STEM 教育机构管理工具** 营销展示网站  
**核心差异化**：硬件设备管理、实验项目管理、创客空间调度、Token 计费系统  
**参考对标**：https://www.matux.tech/institution-dashboard（普通教培）→ 我们要突出 **STEM 特色**  
**预计周期**：8-10 周  
**技术栈**：Next.js + TypeScript + TailwindCSS + Vercel

## ⚠️ 注意事项

1. **不要跳过原型设计**：充分的前期设计可以避免后期返工
2. **Demo 数据安全**：确保只读权限，定期重置数据
3. **性能优先**：首屏加载时间控制在 2 秒以内
4. **SEO 从第一天开始**：不要等到最后才考虑 SEO
5. **移动端适配**：至少 50% 的流量来自移动端
