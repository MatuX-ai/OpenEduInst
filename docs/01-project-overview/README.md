## 项目简介

**OpenMT** 是专为 **STEM 教育**（科学、技术、工程、数学）设计的开源机构管理系统。与普通教培系统不同，OpenMT 专注于：

- 🔧 **硬件设备全生命周期管理**（Arduino / Raspberry Pi / 传感器租赁、维护、损耗追踪）
- 🧪 **实验项目与课程管理**（机器人竞赛、创客作品、编程项目归档）
- 💰 **Token 计费系统**（AI 助教、智能评测、课程生成按需付费）
- 🏭 **创客空间调度**（实验室预约、设备共享、安全准入管理）

**定位**：面向四种组织类型的一站式 STEM 教育管理平台

1. **培训机构** —— 商业化 STEM 课程运营
2. **K12 学校** —— 校内科创教育与社团管理
3. **职业学校** —— 实训基地与职业技能认证
4. **教育局** —— 区域 STEM 教育监管与资源调配
