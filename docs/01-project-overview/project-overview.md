## 项目愿景

打造面向 **STEM 教育** 的开源机构管理平台，让硬件管理、实验项目、创客空间、AI 教学辅助成为每个教育机构的标配能力，推动 STEM 教育在各类组织中的标准化、专业化落地。

---

## 产品定位

OpenMT 是一个**专为 STEM 教育（科学、技术、工程、数学）设计的开源机构管理系统**。与普通教培系统不同，OpenMT 专注于以下核心能力：

| 能力 | 说明 |
|------|------|
| 🔧 硬件设备全生命周期管理 | Arduino / Raspberry Pi / 传感器等设备的入库、借用、维护、损耗追踪 |
| 🧪 实验项目与课程管理 | 机器人竞赛、创客作品、编程项目的教学归档与成果展示 |
| 💰 Token 计费系统 | AI 助教、智能评测、课程生成等增值功能按需付费 |
| 🏭 创客空间调度 | 实验室预约、设备共享、安全准入管理 |

**产品形态**：
- **开源社区版**：本地部署，基础功能
- **云托管版**：SaaS 云端服务，高级 AI + 自动备份 + 多端同步
- **商业定制版**：根据机构需求定制功能与部署方案

## 核心价值主张

### 1. 开箱即用

注册即可使用，无需服务器、数据库、运维团队。标准化的业务流程，降低 STEM 教育机构的信息化门槛。

### 2. STEM 专属

硬件设备管理、实验项目管理、Token 计费、创客空间调度等差异化功能，聚焦 STEM 教育的独特业务场景。

### 3. 数据安全

企业级 SSL/TLS 加密、多租户物理隔离、符合教育行业合规标准，保护学员数据安全。

### 4. 智能驱动

云端大模型赋能的 AI 助教、智能排课、学情分析，让教师从繁琐工作中解放出来。

### 5. 多端同步

Web / 平板 / 手机端数据秒级同步，随时随地管理机构业务。

## 目标用户与典型画像

### 机构层面用户

| 角色 | 典型画像 | 核心诉求 |
|------|---------|---------|
| **培训机构负责人** | 星海机器人培训中心校长，管理 3 个校区、300+ 学员 | 营收增长、学员续费、设备资产管控 |
| **K12 教务主任** | 实验小学科创中心负责人，全校 1,250 名学生 | 排课效率、家校沟通、学生成果展示 |
| **职业学校管理员** | 职业技术学校实训主任，856 名在训学生 | 实训安全、技能认证、就业对接 |
| **教育局监管者** | 县区级教育局 STEM 教育管理部门 | 区域均衡、安全监管、资源调配 |

### 终端使用者

| 角色 | 典型场景 | 核心诉求 |
|------|---------|---------|
| **授课教师** | Arduino 专家、Python 导师、机器人教练 | 课堂反馈、学员评价、课时统计 |
| **招生顾问** | 活动推广、线索跟进、转化分析 | 客户管理、转化率提升 |
| **家长 / 学员** | 课程学习、作品查看、续费报名 | 学习进度、课堂反馈、便捷操作 |

## 四种组织类型对比

| 维度 | 培训机构 | K12 学校 | 职业学校 | 教育局 |
|------|---------|---------|---------|--------|
| **核心目标** | 营收增长、学员续费 | 教学质量、学生发展 | 技能认证、就业对接 | 区域均衡、安全监管 |
| **主要用户** | 管理员、招生顾问、教师 | 校长、教务主任、教师 | 实训主任、企业导师 | 教育局官员、督导员 |
| **关键痛点** | 设备损耗、排课冲突 | 家校沟通、成果展示 | 安全管理、设备维护 | 数据统计、资源调配 |
| **STEM 特色** | 硬件租赁、Token 计费 | 班级设备、作品展示 | 工业设备、安全准入 | 资源调度、质量监测 |
| **商业模式** | B2C 收费培训 | 政府拨款 / 学费 | 政府拨款 + 企业合作 | 财政拨款 |
| **核心指标** | 在训学员数、月度营收、消课率、设备使用率 | 在训学生数、课程完成率、设备完好率、竞赛获奖数 | 实训设备利用率、技能认证通过率、就业对接率 | 辖区学校数、设备资源总量、师资覆盖率、学生参与率 |

## 与普通教培系统的区别

**OpenMT 不是通用教培系统**。以下为关键差异：

| 维度 | OpenMT | 普通教培系统 |
|------|--------|-------------|
| **核心定位** | STEM 教育专属管理平台 | 通用文化课 / 艺术培训管理 |
| **硬件设备管理** | ✅ 全生命周期管理（扫码借出、押金管理、损耗追踪） | ❌ 无或仅基础记录 |
| **实验项目管理** | ✅ 项目里程碑、代码仓库集成、作品展示、竞赛归档 | ❌ 无此能力 |
| **Token 计费** | ✅ AI 助教、智能评测、课程生成按需付费 | ❌ 无 AI 增值功能 |
| **创客空间调度** | ✅ 实验室预约、设备配套、安全准入、使用记录 | ❌ 无此能力 |
| **组织类型适配** | ✅ 培训机构 / K12 / 职校 / 教育局 四种类型 | ❌ 单一教培场景 |
| **工业级设备** | ✅ PLC、CNC、工业机器人等专业设备管理 | ❌ 不涉及 |
| **区域监管能力** | ✅ 教育局驾驶舱、辖区数据统计、安全预警 | ❌ 无监管视角 |

> 详细对比请参考 [09-appendices/comparison-documents/stem-features-comparison.md](../09-appendices/comparison-documents/stem-features-comparison.md)
