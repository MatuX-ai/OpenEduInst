---

### [v1.0.0] - 2026-06-23 (开源社区版)

**初始版本发布**

**核心功能**:
- ✨ 用户与角色管理 (admin, operator, teacher, finance, parent)
- ✨ 机构信息管理
- ✨ 学员档案管理 (添加、编辑、搜索、导入导出)
- ✨ 课程与班级管理
- ✨ 日历视图排课 (月/周/日视图)
- ✨ 课时考勤标记 (出勤/缺勤/迟到/请假)
- ✨ 财务订单管理
- ✨ 退款处理
- ✨ 数据统计仪表盘 (学员数、收入、出勤率)
- ✨ 数据备份与恢复

**技术实现**:
- 前端: Angular 17 + PrimeNG + ECharts
- 后端: FastAPI (Python 3.11)
- 数据库: PostgreSQL 15
- 缓存: Redis 7
- 容器化: Docker + Docker Compose
- 认证: JWT + bcrypt 密码哈希
