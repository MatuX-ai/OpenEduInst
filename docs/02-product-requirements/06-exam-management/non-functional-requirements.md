## NFR-EXAM-PERF — 性能要求

### NFR-EXAM-PERF-001 — 题库同步性能

- **描述**：外部题库同步时的数据加载性能
- **指标**：
  - 单次同步 500 题以内 < 30 秒
  - 批量同步 2000 题以内 < 2 分钟
  - 同步过程显示进度条，支持断点续传
- **优先级**：P0
- **状态**：🎯 待实现

### NFR-EXAM-PERF-002 — 试题列表加载

- **描述**：题库浏览页面试题列表加载性能
- **指标**：每页 20 条试题，列表加载 < 1.5 秒；筛选条件变更后结果刷新 < 1 秒
- **优先级**：P0
- **状态**：🎯 待实现

### NFR-EXAM-PERF-003 — 试卷排版渲染

- **描述**：试卷排版预览的渲染性能
- **指标**：
  - 50 题以内试卷排版预览生成 < 2 秒
  - 100 题以内试卷排版预览生成 < 4 秒
  - PDF 导出 50 题试卷 < 5 秒
- **优先级**：P1
- **状态**：🎯 待实现

### NFR-EXAM-PERF-004 — 在线考试并发

- **描述**：同一考试任务支持的学生并发答题能力
- **指标**：单场考试支持 200 名学生同时在线答题；答题数据实时保存延迟 < 500ms
- **优先级**：P0
- **状态**：🎯 待实现

### NFR-EXAM-PERF-005 — 自动批改性能

- **描述**：客观题自动批改的响应时间
- **指标**：学生提交试卷后，客观题批改结果 < 3 秒返回
- **优先级**：P1
- **状态**：🎯 待实现

### NFR-EXAM-PERF-006 — 试题库规模

- **描述**：系统支持的最大试题存储规模
- **指标**：单机构支持 50,000+ 道试题存储；总试题库支持 500,000+ 道试题
- **优先级**：P1
- **状态**：🎯 待实现

## NFR-EXAM-SEC — 安全要求

### NFR-EXAM-SEC-001 — 考试防作弊

- **描述**：线上考试过程中的防作弊机制
- **规格**：
  - 考试期间禁止复制粘贴操作（通过前端事件拦截）
  - 考试期间检测页面切换（Tab 切换/窗口失焦）并记录
  - 教师端可查看学生页面切换记录
  - 可选开启摄像头监考（Phase 4 增强功能）
- **优先级**：P0
- **状态**：🎯 待实现

### NFR-EXAM-SEC-002 — 试卷内容安全

- **描述**：试卷内容在传输和存储过程中的安全保护
- **规格**：
  - 试卷内容（含答案）API 传输全程 HTTPS 加密
  - 数据库中试题答案字段加密存储
  - PDF 导出文件可设置密码保护
  - 试卷打印文件添加水印（机构名称 + 操作人 + 时间戳）
- **优先级**：P0
- **状态**：🎯 待实现

### NFR-EXAM-SEC-003 — 考试时间控制

- **描述**：严格的时间控制，防止学生超时答题
- **规格**：
  - 服务端独立计时，不依赖客户端时间
  - 考试时长耗尽后服务端自动提交，客户端不可绕过
  - 截止时间到达后，所有未提交考生自动提交
  - 考试时间偏差容忍度 < 5 秒
- **优先级**：P0
- **状态**：🎯 待实现

### NFR-EXAM-SEC-004 — 数据权限隔离

- **描述**：考试数据的多租户和角色权限隔离
- **规格**：
  - 机构 A 的题库、试卷、考试任务不可被机构 B 访问
  - 教师只能管理自己创建的试卷和考试任务
  - 学员只能查看自己被分配的考试和本人成绩
  - 家长只能查看关联学员的考试成绩
- **优先级**：P0
- **状态**：🎯 待实现

### NFR-EXAM-SEC-005 — 外部题库 API 安全

- **描述**：与外部题库 API 通信的安全保障
- **规格**：
  - API Key/Token 加密存储，不在日志中明文记录
  - 外部 API 调用使用 HTTPS
  - 请求频率限制：每秒不超过 10 次请求
  - 外部 API 响应数据校验，防止注入攻击
- **优先级**：P1
- **状态**：🎯 待实现

### NFR-EXAM-SEC-006 — 操作审计

- **描述**：关键操作的审计日志记录
- **规格**：
  - 记录试卷创建/修改/删除操作
  - 记录考试任务创建/发布/取消操作
  - 记录成绩修改操作（含修改前后的值）
  - 记录外部题库同步操作
  - 审计日志保留 ≥ 1 年
- **优先级**：P1
- **状态**：🎯 待实现

## NFR-EXAM-AVAIL — 可用性要求

### NFR-EXAM-AVAIL-001 — 考试期间高可用

- **描述**：考试进行期间的系统可用性保障
- **指标**：考试进行期间系统可用性 ≥ 99.9%；考试服务不可用时间 < 5 分钟/月
- **优先级**：P0
- **状态**：🎯 待实现

### NFR-EXAM-AVAIL-002 — 答题数据持久性

- **描述**：学生答题进度的数据安全保障
- **指标**：
  - 答题数据每 30 秒自动保存，数据丢失风险 ≤ 30 秒的答题内容
  - 服务端异常恢复后，学生可从中断处继续答题
  - 答题数据定期备份，RPO ≤ 1 小时
- **优先级**：P0
- **状态**：🎯 待实现

### NFR-EXAM-AVAIL-003 — 外部题库容错

- **描述**：外部题库服务不可用时的降级策略
- **指标**：
  - 外部题库不可用时，已缓存的本地题库可正常使用
  - 外部题库 API 超时时间 30 秒，超时后显示友好提示
  - 外部题库不可用不影响试卷组卷（使用本地题库）和考试进行
- **优先级**：P1
- **状态**：🎯 待实现

## NFR-EXAM-UX — 用户体验要求

### NFR-EXAM-UX-001 — 组卷操作体验

- **描述**：组卷流程的交互体验
- **规格**：
  - 试题选择支持拖拽添加到试卷
  - 试卷内题目支持拖拽排序
  - 随机抽题操作 < 3 步完成（选择题型 → 输入数量 → 点击抽取）
  - 操作有明确反馈（成功/失败提示、加载状态）
- **优先级**：P0
- **状态**：🎯 待实现

### NFR-EXAM-UX-002 — 考试界面简洁

- **描述**：学生端在线考试界面的设计原则
- **规格**：
  - 界面简洁，仅显示考试相关信息，减少干扰
  - 剩余时间倒计时始终可见
  - 题目导航清晰，已答/未答状态一目了然
  - 提交按钮位置明显但需二次确认，防止误操作
  - 支持键盘快捷键：Tab 切换选项、Enter 下一题
- **优先级**：P1
- **状态**：🎯 待实现

### NFR-EXAM-UX-003 — 打印预览体验

- **描述**：试卷排版打印预览的交互体验
- **规格**：
  - 排版设置变更即时在预览区反映
  - 预览支持缩放、全屏查看
  - 打印按钮一键调用浏览器打印对话框
  - PDF 导出提供下载进度提示
- **优先级**：P1
- **状态**：🎯 待实现

### NFR-EXAM-UX-004 — 响应式适配

- **描述**：考试管理功能在不同设备上的适配
- **规格**：
  - 教师端（题库管理、组卷、排版）：桌面端（1280px+）完整功能，平板端（768px+）核心功能可用
  - 学生端（在线考试）：桌面端完整功能，平板端可用，移动端基础可用
  - 试卷打印预览：仅桌面端完整支持
- **优先级**：P1
- **状态**：🎯 待实现

### NFR-EXAM-UX-005 — 无障碍访问

- **描述**：考试界面的无障碍访问支持
- **规格**：
  - 表单控件有明确的 label 和 aria 标签
  - 颜色对比度符合 WCAG 2.1 AA 标准
  - 倒计时提醒同时提供视觉和听觉提示（可选）
  - 支持键盘完整操作考试全流程
- **优先级**：P2
- **状态**：🎯 待实现

## NFR-EXAM-COMPAT — 兼容性要求

- **规格**：Google Chrome 90+；Microsoft Edge 90+；Safari 14+；Firefox 90+

- **状态**：🎯 待实现

## NFR-EXAM-DATA — 数据规范要求

### NFR-EXAM-DATA-001 — 试题内容格式

- **描述**：试题内容的数据格式规范
- **规格**：
  - 题干内容支持 Markdown 格式（含图片、代码块、表格、数学公式 LaTeX）
  - 选项以 JSON 数组存储，支持富文本
  - 答案格式统一：选择题存储选项字母（A/B/C/D），多选题存储选项字母数组，填空题存储关键词列表
- **优先级**：P0
- **状态**：🎯 待实现

### NFR-EXAM-DATA-002 — 考试成绩保留

- **描述**：考试成绩数据的保留策略
- **规格**：
  - 考试成绩数据永久保留，不随学生毕业/退学而删除
  - 试卷归档后数据保留，不可物理删除
  - 机构注销时，提供 90 天数据导出窗口期
- **优先级**：P1
- **状态**：🎯 待实现

### NFR-EXAM-DATA-003 — 数据导出格式

- **描述**：成绩和试卷数据的导出格式
- **规格**：
  - 成绩数据支持导出为 Excel（.xlsx）和 CSV 格式
  - 试卷支持导出为 PDF 格式
  - 试题支持导出为 Word（.docx）和 Markdown 格式
  - 导出文件命名规范：`{机构名称}_{内容类型}_{日期}.{扩展名}`
- **优先级**：P1
- **状态**：🎯 待实现
