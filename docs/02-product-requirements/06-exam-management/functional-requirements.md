## FR-EXAM-01 — 题库获取模块

- **描述**：教师通过系统对接外部题库 API（`https://opensciedu.matux.tech/`）获取标准化试题资源，支持多维度筛选、浏览和本地缓存，为后续组卷提供试题来源。
- **优先级**：P0
- **状态**：🎯 待实现

### 功能清单

#### 1.1 外部题库对接

- 系统通过 HTTP API 对接 `https://opensciedu.matux.tech/` 外部题库服务
- 支持 API 认证（API Key / Token 方式），配置存储在机构级别
- 自动同步外部题库的科目分类、题型定义等元数据
- 支持增量同步：仅拉取新增/变更的试题，避免全量重复拉取
- 同步状态记录：记录每次同步的时间、试题数量、成功/失败状态
- 同步失败时提供错误详情和重试机制

#### 1.2 多维度试题筛选

- **科目筛选**：按教程科目或机器人等级考试级别筛选（如机器人1级、机器人2级、Python、Scratch 等）
- **难度筛选**：支持 easy（简单）、medium（中等）、hard（困难）、expert（专家）四级筛选
- **题型筛选**：支持 single_choice（单选题）、multi_choice（多选题）、true_false（判断题）、fill_blank（填空题）、short_answer（简答题）、essay（论述题）、coding（编程题）
- **来源筛选**：区分外部题库（external）与本地题库（local）
- **关键词搜索**：支持在题干内容中全文搜索
- **标签筛选**：支持按知识点标签（如"传感器"、"机械结构"、"循环语句"）进行筛选
- 支持多条件组合筛选，筛选条件可保存为"常用筛选"快捷方式

#### 1.3 试题浏览与预览

- 试题列表分页展示，默认每页 20 条
- 列表展示试题关键信息：题型标签、难度标签、科目标签、题干摘要
- 点击试题可展开查看完整内容，包括选项、答案、解析
- 列表顶部显示筛选结果统计（共 X 题，当前筛选 Y 题）
- 支持批量选择试题，已选试题高亮显示

#### 1.4 本地题库管理

- 支持将外部题库试题导入本地题库（本地缓存）
- 本地题库支持机构级别数据隔离
- 支持教师手动创建本地试题（不依赖外部题库）
- 本地试题编辑：修改题干、选项、答案、解析、难度、标签
- 试题状态管理：active（启用）/ archived（归档）
- 支持批量导入试题（Excel / CSV 格式）

## FR-EXAM-02 — 试卷排版与打印模块

- **描述**：实现试卷的自动排版功能，支持自定义纸张大小、页眉页脚、题目间距等格式设置，并提供打印预览及直接打印/导出 PDF 功能。
- **优先级**：P1
- **状态**：🎯 待实现

### 功能清单

#### 2.1 自动排版引擎

- 基于试卷结构（大题分组、题目顺序）自动生成排版布局
- 自动分页：根据纸张大小、页边距、题目内容长度自动计算分页
- 智能排版规则：
  - 选择题选项自动排列（横排 2/4 列或竖排，根据选项长度自适应）
  - 同一道题不跨页分割
  - 大题标题自动加粗居中
  - 编程题/论述题预留作答空白区域
- 排版结果实时预览，修改设置即时生效

#### 2.2 纸张与页面设置

- 纸张大小：支持 A4、A3、B4、B5、Letter、Legal 及自定义尺寸
- 页边距：上/下/左/右独立设置，单位 mm，默认上 25mm、下 20mm、左 30mm、右 20mm
- 页面方向：纵向 / 横向
- 分栏布局：单栏 / 双栏（适合选择题密集的试卷）

#### 2.3 页眉页脚设置

- 页眉：
  - 左侧：支持自定义文本（如"机密★启用前"）或留空
  - 右侧：支持占位符 `{科目名称}`、`{试卷标题}`、`{第{p}页}`（p 为页码）
- 页脚：
  - 左侧：支持占位符 `{科目名称}`、`{日期}`、`{机构名称}`
  - 右侧：支持占位符 `{第{p}页/共{total}页}` 或自定义文本
- 页眉页脚字体大小、样式可独立设置

#### 2.4 题目格式设置

- 题目间距：紧凑 / 普通 / 宽松 三档可选
- 字号设置：
  - 试卷标题字号：二号 / 小二 / 三号 / 四号
  - 大题标题字号：三号 / 四号 / 小四
  - 正文字号：小四 / 五号 / 小五
- 行距：1.0 / 1.5 / 2.0 倍行距
- 分值显示：可选显示/隐藏每题分值
- 得分区显示：可选在每题右侧或左侧显示得分框（____分）
- 答案解析：可选是否在试卷末尾附带答案解析
- 密封线：可选是否显示密封线（姓名、准考证号填写区）

#### 2.5 打印预览与输出

- 打印预览：WYSIWYG 实时预览，支持缩放（50%-200%）
- 分页导航：支持翻页查看、跳转到指定页
- 导出 PDF：将排版后的试卷导出为 PDF 文件，支持下载
- 直接打印：调用浏览器打印 API，支持选择打印机、打印份数、双面打印
- 打印模板保存：将当前排版设置保存为模板，下次可快速复用
- 打印模板管理：模板列表，支持编辑、删除、设为默认

## FR-EXAM-03 — 试题组织模块

- **描述**：支持教师手动选择或随机抽取题目组建试卷，可设置各题型分值、总分及考试时间，是考试管理的核心组卷环节。
- **优先级**：P0
- **状态**：🎯 待实现

### 功能清单

#### 3.1 手动组卷

- 从题库中逐题选择添加到试卷，支持拖拽排序
- 试卷按"大题（Section）"组织，每道大题可包含多个小题
- 大题类型与内置题型对应：选择题、判断题、填空题、简答题、编程题等
- 大题内题目可按序号拖拽调整顺序
- 大题之间可拖拽调整顺序
- 支持添加/删除大题
- 每题可单独设置分值，或批量设置大题内所有题目分值
- 提供试题预览卡片，显示题干摘要、答案（可切换隐藏/显示）

#### 3.2 随机抽题组卷

- 按题型指定抽取数量：如"从选择题库中随机抽取 20 题"
- 按难度分布指定抽取比例：如"简单 30%、中等 50%、困难 20%"
- 按知识点/标签指定抽取范围：如"传感器相关题目不低于 5 题"
- 防重复抽取：同一试卷中不会出现重复题目
- 随机结果不满意可重新抽取
- 支持在随机结果基础上手动调整（增删替换题目）

#### 3.3 试卷信息设置

- 试卷标题：必填，建议格式如"机器人技术等级考试（一级）模拟卷"
- 试卷描述：选填，简要说明试卷用途
- 考试时长：分钟数，如 60 分钟
- 试卷总分：自动计算（各题分值之和），也可手动覆盖
- 试卷状态：draft（草稿）/ published（已发布）/ archived（已归档）

#### 3.4 试卷管理

- 试卷列表：按创建时间、状态、科目筛选
- 试卷搜索：按标题关键词搜索
- 试卷预览：以学生视角完整预览试卷
- 试卷复制：从已有试卷快速复制创建新试卷
- 试卷编辑：修改试卷信息、增删换题目
- 试卷删除：草稿状态可删除，已发布试卷需先归档再删除
- 试卷版本管理：每次修改保存版本记录，可回退到历史版本

## FR-EXAM-04 — 线上考试安排模块

- **描述**：允许教师创建线上考试任务，指定考试时间、参与学生范围、考试时长及提交方式，支持学生在线答题与教师阅卷管理。
- **优先级**：P1
- **状态**：🎯 待实现

### 功能清单

#### 4.1 考试任务创建

- 选择已发布的试卷作为考试内容
- 考试模式选择：
  - 线上考试（online）：学生在系统内在线答题
  - 线下考试（offline）：仅记录考试任务，不提供在线答题功能
- 考试名称：自定义考试任务名称
- 时间设置：
  - 考试开始时间：学生可进入考试的最早时间
  - 考试截止时间：学生必须在此时间前完成考试
  - 考试时长：从学生开始答题起算的限时（分钟），到截止时间仍未完成则自动提交
  - 迟到策略：可选是否允许迟到学生在截止时间前进入考试
- 参与范围：
  - 按班级添加：选择已有班级，班级内所有学员自动参与
  - 按学员添加：手动选择个别学员
  - 支持同时使用两种方式，去重合并
- 提交方式：
  - 在线提交：学生在考试界面直接作答并提交
  - 上传附件：学生上传答题文件（如 Word、PDF、图片）
  - 手动录入：教师手动为学生录入成绩（适用于线下考试转线上记录）

#### 4.2 考试发布与管理

- 发布考试：保存并发布考试任务，系统自动向参与学生推送通知
- 考试状态流转：
  - pending（待开始）：考试尚未到达开始时间
  - in_progress（进行中）：考试开始后，学生在规定时间内可答题
  - ended（已结束）：考试截止时间已过，或所有学生已提交
- 考试任务编辑：待开始状态的考试可修改配置，进行中/已结束的考试不可修改
- 考试任务取消：可取消未开始的考试任务，已开始不可取消
- 考试任务列表：按状态、时间筛选，搜索考试名称

#### 4.3 在线答题（学生端）

- 考试入口：学生可在首页/通知中心看到待参加的考试，点击进入
- 考试说明页：展示考试名称、时长、题目数量、总分、注意事项
- 答题界面：
  - 左侧/顶部：题目导航（题号列表，已答/未答状态标记）
  - 右侧/主体：当前题目内容与作答区
  - 顶部状态栏：剩余时间倒计时、已答题数/总题数
  - 支持题目间自由跳转（非强制顺序作答，除非教师设置）
- 倒计时提醒：剩余 10 分钟、5 分钟、1 分钟时弹窗提醒
- 自动保存：每 30 秒自动保存答题进度到服务器，防止意外丢失
- 断线重连：网络中断后恢复时，自动恢复答题状态
- 提交确认：点击提交后二次确认，确认后不可修改
- 超时自动提交：考试时长耗尽或截止时间到达时，系统自动提交当前答案

#### 4.4 阅卷与成绩管理

- 客观题自动批改：单选题、多选题、判断题、填空题提交后立即自动评分
- 主观题手动批改：
  - 教师阅卷界面：按学生逐题批改，显示学生答案与参考答案
  - 支持打分和文字评语
  - 批改进度追踪：已批/未批/总数
- 成绩发布策略：
  - 即时发布：学生提交后立即看到客观题得分
  - 统一发布：所有学生完成且教师批改完毕后统一发布总成绩
- 成绩统计：
  - 学生成绩列表：按得分排序，导出 Excel
  - 成绩分布：分数段统计（柱状图）、平均分、最高分、最低分、及格率
  - 题目分析：每题正确率/得分率，识别难题/易错题
- 成绩查看：
  - 教师端：查看所有学生成绩，可导出
  - 学生端：查看本人成绩、答题详情、正确答案与解析
  - 家长端：查看关联学员成绩
