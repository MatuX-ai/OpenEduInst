## 授课教师角色

### US-TEACHER-EXAM-001 — 浏览外部题库

**作为**：授课教师，**我希望**能访问并浏览外部题库资源，**以便**为我的课程找到合适的考试题目。

- **验收标准**：可在考试管理模块进入题库浏览页面；能按科目、难度、题型筛选试题；可查看试题详情（含答案和解析）；可关键词搜索试题
- **优先级**：P0
- **关联 FR**：FR-EXAM-01

### US-TEACHER-EXAM-002 — 同步外部题库

**作为**：授课教师，**我希望**能将外部题库的试题同步到本地题库，**以便**在外部题库不可用时仍能正常使用试题资源。

- **验收标准**：可点击"同步题库"触发同步；同步过程显示进度条；同步完成后显示本次新增/更新的试题数量；同步失败时显示错误原因
- **优先级**：P0
- **关联 FR**：FR-EXAM-01

### US-TEACHER-EXAM-003 — 手动创建本地试题

**作为**：授课教师，**我希望**能手动创建本地试题，**以便**补充外部题库不包含的自定义题目。

- **验收标准**：有"创建试题"入口；支持选择题目类型（选择题、判断题、填空题、简答题、编程题等）；支持设置难度、科目、标签；支持录入题干、选项、答案和解析；创建后试题出现在本地题库中
- **优先级**：P1
- **关联 FR**：FR-EXAM-01

### US-TEACHER-EXAM-004 — 手动组建试卷

**作为**：授课教师，**我希望**能手动从题库中选择题目组建试卷，**以便**根据教学进度和重点精确控制试卷内容。

- **验收标准**：可从题库中选题添加到试卷；支持按大题分组组织题目；可调整题目顺序；可单独设置每题分值；试卷总分自动计算
- **优先级**：P0
- **关联 FR**：FR-EXAM-03

### US-TEACHER-EXAM-005 — 随机抽题组卷

**作为**：授课教师，**我希望**能通过随机抽题方式快速组建试卷，**以便**高效生成多套不重复的试卷。

- **验收标准**：可选择题型并指定抽取数量；可设置难度分布比例；可指定知识点范围；抽取结果不满意可重新抽取；支持在随机结果基础上手动调整
- **优先级**：P0
- **关联 FR**：FR-EXAM-03

### US-TEACHER-EXAM-006 — 试卷排版与打印

**作为**：授课教师，**我希望**能对试卷进行排版并打印，**以便**用于线下纸质考试。

- **验收标准**：可进入试卷排版页面；支持设置纸张大小、页边距、字体字号；支持设置页眉页脚；实时预览排版效果；可导出 PDF 或直接打印
- **优先级**：P1
- **关联 FR**：FR-EXAM-02

### US-TEACHER-EXAM-007 — 保存打印模板

**作为**：授课教师，**我希望**能保存排版设置为模板，**以便**下次快速复用相同的排版格式。

- **验收标准**：排版设置可保存为模板；模板列表可查看；可选择模板快速应用；支持编辑和删除模板
- **优先级**：P2
- **关联 FR**：FR-EXAM-02

### US-TEACHER-EXAM-008 — 创建线上考试任务

**作为**：授课教师，**我希望**能创建线上考试任务，**以便**组织学生进行在线考试。

- **验收标准**：可选择已发布的试卷创建考试；可设置考试开始/截止时间和时长；可选择参与学生（按班级或按人）；可发布考试任务并通知学生
- **优先级**：P1
- **关联 FR**：FR-EXAM-04

### US-TEACHER-EXAM-009 — 批改主观题

**作为**：授课教师，**我希望**能批改学生提交的主观题，**以便**完成考试评分。

- **验收标准**：阅卷界面按学生逐题展示；可查看学生答案与参考答案对比；可为每道主观题打分和写评语；批改进度一目了然
- **优先级**：P1
- **关联 FR**：FR-EXAM-04

### US-TEACHER-EXAM-010 — 查看成绩统计

**作为**：授课教师，**我希望**能查看考试的成绩统计和分析，**以便**了解学生的整体表现和教学效果。

- **验收标准**：可查看成绩列表（按得分排序）；可查看分数段分布统计；可查看每题正确率/得分率；可导出成绩数据为 Excel
- **优先级**：P1
- **关联 FR**：FR-EXAM-04

## 机构管理员角色

### US-ADMIN-EXAM-001 — 配置外部题库连接

**作为**：机构管理员，**我希望**能配置外部题库 API 的连接信息，**以便**机构内的教师可以使用外部题库资源。

- **验收标准**：可在机构设置中配置外部题库 API 地址和认证信息；可测试连接是否正常；连接信息加密存储
- **优先级**：P1
- **关联 FR**：FR-EXAM-01

### US-ADMIN-EXAM-002 — 管理所有考试任务

**作为**：机构管理员，**我希望**能查看和管理机构内所有教师创建的考试任务，**以便**掌握全局考试安排。

- **验收标准**：可查看所有考试任务列表；可按状态、时间、创建教师筛选；可取消不合理的考试任务；可查看所有考试的成绩统计
- **优先级**：P1
- **关联 FR**：FR-EXAM-04

### US-ADMIN-EXAM-003 — 管理试卷模板

**作为**：机构管理员，**我希望**能管理机构的试卷和打印模板，**以便**统一机构的考试标准和格式。

- **验收标准**：可查看所有试卷列表；可设置机构级别的默认打印模板；可归档/删除过期试卷
- **优先级**：P2
- **关联 FR**：FR-EXAM-02, FR-EXAM-03

## 教务主管角色

### US-OPERATOR-EXAM-001 — 统筹考试安排

**作为**：教务主管，**我希望**能查看机构内所有考试的时间安排，**以便**避免考试时间冲突并合理规划教学日程。

- **验收标准**：有考试日历视图（周/月）；可查看每场考试的时间、科目、参与学生数；可检测同一班级/学生的时间冲突
- **优先级**：P1
- **关联 FR**：FR-EXAM-04

### US-OPERATOR-EXAM-002 — 考试通知管理

**作为**：教务主管，**我希望**能在考试发布时自动通知学生和家长，**以便**确保所有参与者及时知晓考试安排。

- **验收标准**：考试发布后自动向参与学生推送站内通知；可配置是否同时发送短信/邮件通知；可查看通知发送状态
- **优先级**：P2
- **关联 FR**：FR-EXAM-04

## 学员角色

### US-STUDENT-EXAM-001 — 参加线上考试

**作为**：学员，**我希望**能在系统内参加线上考试，**以便**方便地完成考试测评。

- **验收标准**：可在首页看到待参加考试入口；进入考试后显示考试说明和注意事项；答题界面清晰易用；倒计时提醒剩余时间；可提交试卷并看到确认提示
- **优先级**：P1
- **关联 FR**：FR-EXAM-04

### US-STUDENT-EXAM-002 — 查看考试成绩

**作为**：学员，**我希望**能查看我的考试成绩和答题详情，**以便**了解自己的学习情况和薄弱环节。

- **验收标准**：可在个人中心查看成绩列表；可查看每场考试的得分和排名（如教师开放）；可查看每道题的正确答案和解析
- **优先级**：P1
- **关联 FR**：FR-EXAM-04

### US-STUDENT-EXAM-003 — 答题进度保护

**作为**：学员，**我希望**在答题过程中即使遇到网络中断也不会丢失答题进度，**以便**顺利完成考试。

- **验收标准**：答题进度自动保存；网络中断恢复后可继续答题；超时或截止时间到达时自动提交
- **优先级**：P0
- **关联 FR**：FR-EXAM-04

## 家长角色

### US-PARENT-EXAM-001 — 查看孩子考试成绩

**作为**：家长，**我希望**能查看孩子的考试成绩，**以便**了解孩子的学习情况。

- **验收标准**：可在家长端查看关联学员的考试成绩列表；可查看每场考试的得分；可查看教师评语
- **优先级**：P2
- **关联 FR**：FR-EXAM-04
