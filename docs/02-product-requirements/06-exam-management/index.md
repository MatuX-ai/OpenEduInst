## 模块简介

考试管理模块为 OpenMT 教育平台提供完整的考试业务闭环，涵盖题库资源获取、试卷组建与排版、线下打印及线上考试安排四大核心能力。教师可通过该模块从外部题库（`https://opensciedu.matux.tech/`）获取标准化试题资源，灵活组建试卷，并支持线下纸质考试与线上数字化考试两种模式，满足 STEM 教育及机器人等级考试等多种教学场景的测评需求。

## 核心功能模块总览

| 大模块 | 编号 | 说明 | 优先级 |
|--------|------|------|--------|
| 题库获取 | FR-EXAM-01 | 对接外部题库 API，多维度筛选试题 | P0 |
| 试卷排版与打印 | FR-EXAM-02 | 试卷自动排版、格式设置、打印预览与输出 | P1 |
| 试题组织 | FR-EXAM-03 | 手动/随机组卷，分值配置，考试时间设置 | P0 |
| 线上考试安排 | FR-EXAM-04 | 创建线上考试任务，指定时间、范围、提交方式 | P1 |

### 主要数据表定义

#### 题库表（question_banks）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID (PK) | 主键 |
| institution_id | UUID (FK) | 所属机构 |
| name | VARCHAR(200) | 题库名称 |
| source | VARCHAR(50) | 来源：external / local |
| source_url | VARCHAR(500) | 外部题库 API 地址 |
| subject | VARCHAR(100) | 科目分类 |
| description | TEXT | 题库描述 |
| question_count | INTEGER | 试题总数（缓存） |
| last_sync_at | TIMESTAMP | 最后同步时间 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

#### 试题表（questions）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID (PK) | 主键 |
| bank_id | UUID (FK) | 所属题库 |
| external_id | VARCHAR(100) | 外部题库试题 ID |
| type | VARCHAR(20) | 题型：single_choice / multi_choice / true_false / fill_blank / short_answer / essay / coding |
| difficulty | VARCHAR(20) | 难度：easy / medium / hard / expert |
| subject | VARCHAR(100) | 科目 / 等级 |
| content | TEXT | 题目内容（Markdown） |
| options | JSONB | 选项（选择题） |
| answer | TEXT | 正确答案 |
| answer_analysis | TEXT | 答案解析 |
| score | DECIMAL(5,2) | 默认分值 |
| tags | JSONB | 标签数组 |
| status | VARCHAR(20) | 状态：active / archived |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

#### 试卷表（exam_papers）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID (PK) | 主键 |
| institution_id | UUID (FK) | 所属机构 |
| title | VARCHAR(200) | 试卷标题 |
| description | TEXT | 试卷说明 |
| total_score | DECIMAL(6,2) | 总分 |
| duration | INTEGER | 考试时长（分钟） |
| status | VARCHAR(20) | 状态：draft / published / archived |
| format_settings | JSONB | 排版格式设置 |
| created_by | UUID (FK) | 创建人 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

#### 试卷-试题关联表（paper_questions）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID (PK) | 主键 |
| paper_id | UUID (FK) | 试卷 ID |
| question_id | UUID (FK) | 试题 ID |
| order_no | INTEGER | 题目序号 |
| score | DECIMAL(5,2) | 本题分值 |
| section | VARCHAR(50) | 所属大题（如"一、选择题"） |

#### 考试任务表（exam_tasks）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID (PK) | 主键 |
| institution_id | UUID (FK) | 所属机构 |
| title | VARCHAR(200) | 考试任务名称 |
| paper_id | UUID (FK) | 关联试卷 |
| mode | VARCHAR(20) | 考试模式：online / offline |
| start_time | TIMESTAMP | 考试开始时间 |
| end_time | TIMESTAMP | 考试截止时间 |
| duration | INTEGER | 考试时长（分钟） |
| student_ids | JSONB | 参与学生 ID 列表 |
| class_ids | JSONB | 参与班级 ID 列表 |
| submit_type | VARCHAR(20) | 提交方式：online / upload / manual |
| status | VARCHAR(20) | 状态：pending / in_progress / ended |
| auto_grade | BOOLEAN | 是否自动批改客观题 |
| created_by | UUID (FK) | 创建人 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

#### 考试结果表（exam_results）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID (PK) | 主键 |
| exam_id | UUID (FK) | 考试任务 ID |
| student_id | UUID (FK) | 学员 ID |
| answers | JSONB | 答案内容 |
| score | DECIMAL(6,2) | 得分 |
| objective_score | DECIMAL(6,2) | 客观题得分 |
| subjective_score | DECIMAL(6,2) | 主观题得分 |
| start_time | TIMESTAMP | 开始答题时间 |
| submit_time | TIMESTAMP | 提交时间 |
| status | VARCHAR(20) | 状态：pending / in_progress / submitted / graded |
| graded_by | UUID (FK) | 批改人 |
| graded_at | TIMESTAMP | 批改时间 |
| feedback | TEXT | 教师评语 |
