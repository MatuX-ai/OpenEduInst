## Phase 1 验收标准（MVP）

**时间**：第 1-2 月
**交付模块**：实训设备管理 + 系统管理 + 核心看板

### AC-VP1-01 — 实训设备管理可用

| 验收项 | 通过条件 |
|--------|---------|
| 设备分类管理 | 管理员可创建/编辑/删除设备分类，支持 3 级分类体系 |
| 设备入库 | 支持单条录入和 Excel 批量导入（≥1000 条），必填字段校验正确 |
| 设备标签生成 | 可批量生成二维码标签，扫码可查看设备详情 |
| 设备存放定位 | 支持四级定位（楼栋→楼层→实训室→工位），扫码可定位 |
| 设备借用与归还 | 扫码借出和归还，自动记录借用人/时间/用途，逾期提醒 |
| 设备审批流程 | 可按设备类型/价格配置审批规则，审批通过/拒绝需通知 |
| 设备列表查看 | 按分类/状态/实训室筛选，支持分页、搜索、排序 |
| 设备详情页 | 展示完整信息、借用历史、维护记录 |

### AC-VP1-02 — 系统管理可用

| 验收项 | 通过条件 |
|--------|---------|
| 租户创建 | 新学校注册后自动初始化，创建管理员账号 |
| 用户管理 | 支持批量导入学生/教师账号（Excel），角色分配正确 |
| 权限管理 | 预置角色权限正确，可自定义角色 |
| 系统配置 | 学校基本信息、实训室配置可正常编辑保存 |

### AC-VP1-03 — 核心看板可用

| 验收项 | 通过条件 |
|--------|---------|
| 核心指标总览 | 四大指标（在训人数/设备利用率/认证通过率/就业率）数据正确 |
| 设备使用分析 | 趋势图渲染正确，数据按月展示 |
| 设备闲置预警 | 连续 30 天未使用的设备自动列入闲置列表 |

## 通用验收标准

### AC-VGEN-01 — 性能标准

| 验收项 | 通过条件 |
|--------|---------|
| 首屏加载时间 | 核心页面 ≤ 2 秒（模拟 100M 带宽） |
| API 响应时间 | 95% 请求 ≤ 500ms（100 并发） |
| 扫码响应 | 扫码到信息显示 ≤ 1 秒 |
| 批量导入 | 1000 条设备导入 ≤ 10 秒 |

### AC-VGEN-02 — 安全标准

| 验收项 | 通过条件 |
|--------|---------|
| HTTPS 强制 | 非 HTTPS 请求自动跳转 |
| JWT 认证 | Token 过期自动跳转登录，Refresh Token 有效 |
| 权限控制 | 用户只能访问授权范围内的数据和功能 |
| SQL 注入防护 | 输入特殊 SQL 语句不会导致数据泄漏 |
| XSS 防护 | 输入 `<script>` 标签不会在前端执行 |

### AC-VGEN-03 — 兼容性标准

| 验收项 | 通过条件 |
|--------|---------|
| 浏览器兼容 | Chrome 90+、Firefox 90+、Edge 90+、Safari 14+ 正常显示和操作 |
| 移动端适配 | iOS Safari 14+、Android Chrome 90+ 核心功能正常 |
| 扫码设备兼容 | 主流二维码扫描枪扫码后正确跳转 |

### AC-VGEN-04 — 可用性标准

| 验收项 | 通过条件 |
|--------|---------|
| 系统可用性 | 月度可用性 ≥ 99.9% |
| 故障恢复 | 常规故障 ≤ 30 分钟 |
| 数据备份 | 每日全量备份 + 每小时增量备份正常执行 |
| 数据恢复 | 可从任意备份时间点恢复数据 |
