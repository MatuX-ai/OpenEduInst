## AC-OS-001 — API 代理服务验收标准

**关联 FR**：FR-OS-001

1. 后端提供 `/api/resource-proxy/*` 路由
2. 请求被正确转发至 `openmt-api.seduino.org`
3. 代理层添加机构 API Key 认证信息
4. 记录请求日志（不含敏感数据）
5. 支持 tutorials（教程）资源列表和详情查询
6. 支持 courseware（课件）资源列表和详情查询
7. 支持 hardware（硬件项目）资源列表和详情查询
8. 支持按关键词搜索资源
9. 支持分页（page, page_size 参数）
10. 网络异常时返回 HTTP 502 和友好错误消息
11. 上游返回 4xx 错误时正确透传
12. 请求超时默认 10 秒，可配置
13. 失败请求最多重试 2 次
14. 前端不因代理故障而白屏

## AC-OS-002 — 机构集成配置验收标准

**关联 FR**：FR-OS-002

1. 机构设置页面提供 OpenSciEd 集成 Tab
2. 支持启用/禁用开关切换
3. 支持输入和保存机构 API Key
4. API Key 加密存储在数据库中
5. API Key 不以明文形式回显到前端页面
6. 提供"测试连接"按钮验证 API Key 有效性
7. "测试连接"成功显示绿色成功提示
8. "测试连接"失败显示红色错误提示和原因
9. 配置保存后立即生效（无需重启服务）
10. 禁用集成后，资源中心页面显示"未启用"提示
11. 支持重新生成 API Key（旧 Key 失效）
12. 仅机构管理员可访问此配置页面

## AC-OS-003 — 资源中心前端验收标准

**关联 FR**：FR-OS-003

1. 管理后台和教师工作台有资源中心入口
2. 资源中心页面分为教程 Tab、课件 Tab、硬件项目 Tab
3. 资源以卡片形式展示（封面图、标题、简要描述、作者、更新时间）
4. 支持分页（每页 12 条，有上一页/下一页按钮）
5. 支持按关键词搜索资源
6. 支持按标签筛选资源
7. 点击卡片跳转到资源详情页
8. 详情页展示标题、描述、封面图、正文内容
9. 详情页支持附件下载（PDF、Word、PPT、视频等）
10. 资源加载失败显示友好的空态（含图标、提示文字、重试按钮）
11. 点击重试按钮重新请求数据
12. 教师工作台首页展示基于课程类型的推荐资源
13. 支持收藏资源到个人收藏夹
14. 支持查看最近浏览的资源列表
15. 页面响应式布局，移动端可正常使用
16. 未启用集成的机构显示"请先在机构设置中启用 OpenSciEd 集成"提示

## AC-OS-004 — 缓存策略验收标准

**关联 FR**：FR-OS-004

1. 列表接口数据缓存 30 分钟（TTL 可配置）
2. 详情接口数据缓存 60 分钟（TTL 可配置）
3. 搜索结果缓存 15 分钟（TTL 可配置）
4. 缓存 Key 包含机构 ID、资源类型、分页参数、搜索参数
5. 不同机构的缓存互不干扰
6. 缓存命中率可在监控面板查看
7. 机构管理员可手动清除本机构的缓存
8. 手动清除后，下一次请求从上游重新获取数据
9. Redis 不可用时自动降级为直接请求上游
10. 缓存过期自动失效，不阻塞新数据的获取

## AC-OS-005 — 资源使用统计验收标准

**关联 FR**：FR-OS-005

1. 记录每个资源的浏览次数
2. 记录每个资源的下载次数
3. 按资源类型统计使用量
4. 按机构统计使用量
5. 按教师统计使用量
6. 提供热门资源排行榜（Top 10）
7. 统计数据可导出为 CSV
8. 在仪表板首页展示机构的资源使用概况
9. 统计数据支持按时间范围筛选（日/周/月）

## AC-OS-006 — 统一认证验收标准

**关联 FR**：FR-OS-006

1. EduInst 和 OpenMTSciEd 使用相同的 SECRET_KEY 配置
2. 教师在 EduInst 登录后获取的 JWT 可在 OpenMTSciEd 中验证通过
3. OpenMTSciEd 能正确解析 JWT 中的 `userId`、`username`、`role`、`org_id` 字段
4. JWT 中的 `role` 为 `teacher` 时，OpenMTSciEd 自动赋予教师权限
5. 教师从 EduInst 跳转到 OpenMTSciEd 时无需二次登录
6. Token 过期后，OpenMTSciEd 返回友好的"认证已过期，请重新登录"提示
7. 两个平台使用不同的 SECRET_KEY 时，系统能正常报错而不是静默失败
8. 非教师角色的 JWT 在 OpenMTSciEd 中被正确限制权限

## AC-OS-007 — 教师用户同步验收标准

**关联 FR**：FR-OS-007

1. 在 EduInst 创建教师时，自动调用 OpenMTSciEd 用户注册 API 创建对应账号
2. OpenMTSciEd User 表包含 `eduinstUserId` 和 `eduinstOrgId` 字段
3. 同步失败时不阻塞 EduInst 本地操作，并在日志中记录错误详情
4. 教师信息变更（姓名、邮箱）时，OpenMTSciEd 端同步更新
5. 教师被移除机构时，OpenMTSciEd 端标记 `isActive=false`
6. 机构管理员可手动触发全量教师同步
7. 同步状态（成功/失败/待同步）可在机构管理页面查看
8. 支持对同步失败的记录手动重试

## AC-OS-008 — STEM教师管理模块验收标准

**关联 FR**：FR-OS-008

1. 培训机构、K12学校、职业学校的管理后台侧边栏"STEM 教育管理"下出现"STEM教师管理"子菜单
2. 教育局（education_bureau）的管理后台不显示"STEM教师管理"菜单
3. 点击"STEM教师管理"进入模块页面，包含"课件管理"和"统计监察"两个 Tab
4. 机构管理员可见全部两个 Tab
5. 教师角色登录后仅可见"课件管理"Tab，不可见"统计监察"
6. 菜单项带有正确的图标和路由
7. 页面加载时显示加载状态，加载完成后展示内容

## AC-OS-009 — 课件管理入口验收标准

**关联 FR**：FR-OS-009

1. EduInst 后端提供 API 生成带 token 的 OpenMTSciEd 深链 URL
2. 前端"课件管理"页面通过 iframe 嵌入 OpenMTSciEd 课题工作室
3. iframe URL 格式为 `https://opensciedu.matux.tech/topic-studio?token={jwt}`
4. OpenMTSciEd 解析 URL 参数中的 token 后自动完成身份识别
5. 教师在 iframe 内可正常创建、编辑、发布课件
6. iframe 加载失败时显示友好的错误提示和"重试"按钮
7. 页面提供"在新窗口打开"按钮，点击后在新标签页打开课题工作室
8. 教师创建的课件数据可在统计监察页面中体现

## AC-OS-010 — 统计监察验收标准

**关联 FR**：FR-OS-010

1. 统计监察页面以表格形式展示机构下所有教师的课件数据
2. 每位教师展示：课件总数、本月新增课件数、教程数、浏览量、最近活跃时间、审核状态
3. 支持按教师姓名搜索
4. 支持按指标列排序（点击列头切换升序/降序）
5. 支持按时间范围筛选（本周/本月/本季度/自定义日期范围）
6. 页面顶部展示机构汇总卡片：总课件数、总教师数、活跃教师数
7. 数据支持导出为 CSV 文件
8. 数据每小时自动刷新，页面提供"手动刷新"按钮
9. 数据加载中显示骨架屏
10. 无数据时显示友好的空态提示
