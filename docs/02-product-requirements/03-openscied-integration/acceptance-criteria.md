## AC-OS-001 — API 代理服务验收标准

**关联 FR**：FR-OS-001

1. 后端提供 `/api/resource-proxy/*` 路由
2. 请求被正确转发至 `openmt-api.seduino.org`
3. 代理层添加机构 API Key 认证信息
4. 记录请求日志（不含敏感数据）
5. 支持 tutorials（教程）资源列表和详情查询
6. 支持 courseware（课件）资源列表和详情查询
7. 支持 hardware（硬件项目）资源列表和详情查询
8. 支持按关键词搜索资源
9. 支持分页（page, page_size 参数）
10. 网络异常时返回 HTTP 502 和友好错误消息
11. 上游返回 4xx 错误时正确透传
12. 请求超时默认 10 秒，可配置
13. 失败请求最多重试 2 次
14. 前端不因代理故障而白屏

## AC-OS-002 — 机构集成配置验收标准

**关联 FR**：FR-OS-002

1. 机构设置页面提供 OpenSciEd 集成 Tab
2. 支持启用/禁用开关切换
3. 支持输入和保存机构 API Key
4. API Key 加密存储在数据库中
5. API Key 不以明文形式回显到前端页面
6. 提供"测试连接"按钮验证 API Key 有效性
7. "测试连接"成功显示绿色成功提示
8. "测试连接"失败显示红色错误提示和原因
9. 配置保存后立即生效（无需重启服务）
10. 禁用集成后，资源中心页面显示"未启用"提示
11. 支持重新生成 API Key（旧 Key 失效）
12. 仅机构管理员可访问此配置页面

## AC-OS-003 — 资源中心前端验收标准

**关联 FR**：FR-OS-003

1. 管理后台和教师工作台有资源中心入口
2. 资源中心页面分为教程 Tab、课件 Tab、硬件项目 Tab
3. 资源以卡片形式展示（封面图、标题、简要描述、作者、更新时间）
4. 支持分页（每页 12 条，有上一页/下一页按钮）
5. 支持按关键词搜索资源
6. 支持按标签筛选资源
7. 点击卡片跳转到资源详情页
8. 详情页展示标题、描述、封面图、正文内容
9. 详情页支持附件下载（PDF、Word、PPT、视频等）
10. 资源加载失败显示友好的空态（含图标、提示文字、重试按钮）
11. 点击重试按钮重新请求数据
12. 教师工作台首页展示基于课程类型的推荐资源
13. 支持收藏资源到个人收藏夹
14. 支持查看最近浏览的资源列表
15. 页面响应式布局，移动端可正常使用
16. 未启用集成的机构显示"请先在机构设置中启用 OpenSciEd 集成"提示

## AC-OS-004 — 缓存策略验收标准

**关联 FR**：FR-OS-004

1. 列表接口数据缓存 30 分钟（TTL 可配置）
2. 详情接口数据缓存 60 分钟（TTL 可配置）
3. 搜索结果缓存 15 分钟（TTL 可配置）
4. 缓存 Key 包含机构 ID、资源类型、分页参数、搜索参数
5. 不同机构的缓存互不干扰
6. 缓存命中率可在监控面板查看
7. 机构管理员可手动清除本机构的缓存
8. 手动清除后，下一次请求从上游重新获取数据
9. Redis 不可用时自动降级为直接请求上游
10. 缓存过期自动失效，不阻塞新数据的获取

## AC-OS-005 — 资源使用统计验收标准

**关联 FR**：FR-OS-005

1. 记录每个资源的浏览次数
2. 记录每个资源的下载次数
3. 按资源类型统计使用量
4. 按机构统计使用量
5. 按教师统计使用量
6. 提供热门资源排行榜（Top 10）
7. 统计数据可导出为 CSV
8. 在仪表板首页展示机构的资源使用概况
9. 统计数据支持按时间范围筛选（日/周/月）
