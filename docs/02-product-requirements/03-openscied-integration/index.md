## 模块简介

OpenSciEd (Open Science Education) 是一个开放的科学教育资源平台，提供丰富的教程、课件和硬件项目资料。本模块负责将 OpenSciEd 资源通过 API 代理服务集成到培训平台中，为教师和学生提供优质的 STEM 教育内容。

## 核心价值

1. **丰富资源库**：为教师提供丰富的 STEM 教学资源，降低备课门槛
2. **一键集成**：通过 API 代理方式无缝接入，无需手动下载和上传
3. **分类清晰**：资源按类型（教程、课件、硬件项目）组织，易于查找
4. **智能推荐**：根据教师所授课程类型推荐相关资源
5. **实时更新**：上游资源更新后，代理服务自动同步最新内容

## 核心功能模块

| 模块 | 编号 | 说明 | 优先级 |
|------|------|------|--------|
| API 代理服务 | FR-OS-001 | 后端代理转发 OpenSciEd API 请求 | P0 |
| 机构集成配置 | FR-OS-002 | 机构级别的集成开关和 API Key 管理 | P1 |
| 资源中心前端 | FR-OS-003 | 资源列表、详情、搜索和筛选 | P0 |
| 缓存策略 | FR-OS-004 | Redis 缓存减少上游请求，提升响应速度 | P1 |
| 资源使用统计 | FR-OS-005 | 记录资源浏览和使用情况 | P2 |

## 资源类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 教程 (Tutorial) | 面向学生的教学内容 | Scratch入门、Python基础 |
| 课件 (Courseware) | 面向教师的教学材料 | 课程计划、PPT、教案 |
| 硬件项目 (Hardware) | 与硬件相关的项目资料 | Arduino项目、树莓派实验 |
