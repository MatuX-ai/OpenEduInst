## 模块简介

本模块负责将 OpenMTSciEd（`https://opensciedu.matux.tech/`）STEM 科教平台的资源与教师管理能力集成到教育机构管理平台中。除教育局（BUREAU）外的所有组织机构（培训机构、K12学校、职业学校）均可使用本模块，实现：

- **教师账号共享**：两个平台统一认证，教师一次登录即可通行
- **课件自由管理**：教师通过 OpenMTSciEd 的课题工作室自由创建/编辑/发布课件
- **机构统计监察**：机构管理员在 EduInst 端查看教师的 STEM 课件使用数据

## 核心价值

1. **双平台统一认证**：教师账号在 EduInst 和 OpenMTSciEd 间共享，无需重复注册
2. **课件自由管理**：教师通过 OpenMTSciEd 课题工作室自由创建和管理自有课件
3. **机构级监管**：机构管理员可查看所有教师的课件数量、使用量、活跃度等数据
4. **丰富资源库**：为教师提供丰富的 STEM 教学资源，降低备课门槛
5. **一键集成**：通过 API 代理 + 认证桥接方式无缝接入
6. **分类清晰**：资源按类型（教程、课件、硬件项目）组织，易于查找

## 核心功能模块

|------|------|------|--------|
| API 代理服务 | FR-OS-001 | 后端代理转发 OpenMTSciEd API 请求 | P0 |
| 机构集成配置 | FR-OS-002 | 机构级别的集成开关和 API Key 管理 | P1 |
| 资源中心前端 | FR-OS-003 | 资源列表、详情、搜索和筛选 | P0 |
| 缓存策略 | FR-OS-004 | Redis 缓存减少上游请求，提升响应速度 | P1 |
| 资源使用统计 | FR-OS-005 | 记录资源浏览和使用情况 | P2 |
| **统一认证（新增）** | **FR-OS-006** | **双平台 JWT 共享，教师一次登录通行** | **P0** |
| **教师用户同步（新增）** | **FR-OS-007** | **EduInst 创建教师时自动同步到 OpenMTSciEd** | **P0** |
| **STEM教师管理（新增）** | **FR-OS-008** | **非教育局机构菜单中的 STEM 教师管理模块** | **P0** |
| **课件管理入口（新增）** | **FR-OS-009** | **iframe 嵌入 OpenMTSciEd 课件工作室，共享 JWT 免登录** | **P1** |
| **统计监察（新增）** | **FR-OS-010** | **机构级教师课件数据仪表盘（数量/使用量/活跃度）** | **P1** |

| K12学校 (k12_school) | ✅ 是 | 完整 STEM 教师管理 |
