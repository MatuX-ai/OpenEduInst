## NFR-OS-PERF — 性能要求

### NFR-OS-PERF-001 — 列表接口响应

- **描述**：资源列表接口的响应时间
- **指标**：列表接口 P95 响应时间 < 2 秒（含上游响应时间）
- **测量方式**：接口响应时间监控
- **优先级**：P1
- **状态**：✅ 已实现（基于 Redis 缓存）

### NFR-OS-PERF-002 — 详情接口响应

- **描述**：资源详情接口的响应时间
- **指标**：详情接口 P95 响应时间 < 1.5 秒
- **测量方式**：接口响应时间监控
- **优先级**：P1
- **状态**：✅ 已实现

### NFR-OS-PERF-003 — 缓存命中率

- **描述**：Redis 缓存的命中率
- **指标**：列表接口缓存命中率 > 70%
- **优先级**：P2
- **状态**：✅ 已实现

### NFR-OS-PERF-004 — 并发请求

- **描述**：代理服务支持的并发请求数
- **指标**：支持 ≥ 200 并发请求
- **优先级**：P2
- **状态**：✅ 已实现

## NFR-OS-AVAIL — 可用性要求

### NFR-OS-AVAIL-001 — 上游故障降级

- **描述**：当 OpenSciEd 上游服务不可用时的降级策略
- **规格**：前端显示友好的空态和重试按钮，不白屏
- **优先级**：P1
- **状态**：✅ 已实现

### NFR-OS-AVAIL-002 — 请求超时

- **描述**：上游请求超时的处理策略
- **规格**：默认超时时间 10 秒；超时 2 次后返回缓存数据或友好错误
- **优先级**：P1
- **状态**：✅ 已实现

---

## NFR-OS-SEC — 安全要求

### NFR-OS-SEC-001 — API Key 安全

- **描述**：机构 API Key 的安全管理
- **规格**：API Key 仅存储于后端；日志中自动脱敏；禁止前端直接调用；API Key 加密存储
- **优先级**：P0
- **状态**：✅ 已实现

### NFR-OS-SEC-002 — 传输加密

- **描述**：与上游服务的通信加密
- **规格**：全部使用 HTTPS/TLS 1.2+ 加密传输
- **优先级**：P1
- **状态**：✅ 已实现

### NFR-OS-SEC-003 — 请求验证

- **描述**：代理请求的合法性验证
- **规格**：验证用户身份和机构权限；未启用集成的机构禁止访问；速率限制防止滥用
- **优先级**：P1
- **状态**：✅ 已实现

## NFR-OS-COMPAT — 兼容性要求

### NFR-OS-COMPAT-001 — 上游 API 版本

- **描述**：与上游 OpenSciEd API 的版本兼容性
- **规格**：支持上游 API v1.0+；上游版本升级时兼容处理
- **优先级**：P1
- **状态**：✅ 已实现

### NFR-OS-COMPAT-002 — 浏览器兼容

- **描述**：资源浏览功能支持的浏览器
- **规格**：Google Chrome 90+；Microsoft Edge 90+；Safari 14+；Firefox 90+
- **优先级**：P1
- **状态**：✅ 已实现

### NFR-OS-COMPAT-003 — 资源文件格式

- **描述**：支持的资源文件格式
- **规格**：支持 PDF、图片（JPG/PNG/GIF）、Word、PPT、视频（MP4）等常见格式
- **优先级**：P2
- **状态**：✅ 已实现
