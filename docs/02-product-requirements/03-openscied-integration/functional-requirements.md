## FR-OS-001 — API 代理服务

- **描述**：后端服务将前端的资源请求转发到 OpenSciEd 上游 API，并将响应回传给前端
- **关键特性**：
  - 提供统一的 API 入口 `/api/resource-proxy/*`
  - 将请求转发至 `openmt-api.seduino.org`
  - 在代理层添加机构 API Key 认证信息
  - 记录请求日志（不含敏感数据）
  - 支持上游 API 的所有资源类型：tutorials（教程）、courseware（课件）、hardware（硬件项目）
  - 支持列表查询、详情查询、搜索功能
  - 网络异常或上游故障时返回友好的错误响应，不导致前端白屏
  - 支持请求超时配置（默认 10 秒）
  - 支持请求重试（最多 2 次）
- **优先级**：P0
- **状态**：✅ 已实现

## FR-OS-002 — 机构集成配置

- **描述**：机构管理员可配置本机构的 OpenSciEd 集成状态和 API Key
- **关键特性**：
  - 在机构设置页面提供 OpenSciEd 集成 Tab
  - 支持启用/禁用集成（开关切换）
  - 支持输入和保存机构 API Key
  - API Key 加密存储，不回显明文到前端
  - 提供"测试连接"按钮验证 API Key 是否有效
  - 配置保存后立即生效
  - 禁用集成后，资源中心页面显示"未启用"提示
  - API Key 可重新生成（旧 Key 失效）
- **优先级**：P1
- **状态**：✅ 已实现

## FR-OS-003 — 资源中心前端

- **描述**：前端页面展示 OpenSciEd 资源，供教师浏览和使用
- **关键特性**：
  - 资源中心 Tab 页面入口
  - 支持按资源类型切换（教程 Tab / 课件 Tab / 硬件项目 Tab）
  - 资源列表以卡片形式展示（封面图、标题、简要描述、作者、更新时间）
  - 支持分页（每页 12 条）
  - 支持按关键词搜索
  - 支持按标签筛选
  - 点击卡片进入资源详情页
  - 详情页展示完整内容：标题、描述、封面、正文、附件下载
  - 资源加载失败时显示友好的空态和重试按钮
  - 教师工作台首页展示推荐资源（基于教师所授课程类型）
  - 支持收藏资源到个人收藏夹
  - 支持查看最近浏览的资源
  - 响应式布局，移动端可正常使用
- **优先级**：P0
- **状态**：✅ 已实现

## FR-OS-004 — 缓存策略

- **描述**：通过 Redis 缓存减少对上游 API 的重复请求，提升响应速度
- **关键特性**：
  - 列表接口数据缓存 30 分钟（TTL 可配置）
  - 详情接口数据缓存 60 分钟
  - 搜索结果缓存 15 分钟
  - 缓存 Key 包含：机构 ID、资源类型、分页参数、搜索参数
  - 缓存命中率可在监控面板查看
  - 机构管理员可手动清除本机构的缓存
  - 缓存过期自动失效，不影响新数据的获取
  - Redis 不可用时降级为直接请求上游
- **优先级**：P1
- **状态**：✅ 已实现

## FR-OS-005 — 资源使用统计

- **描述**：记录和展示资源的使用情况数据
- **关键特性**：
  - 记录每个资源的浏览次数
  - 记录每个资源的下载次数
  - 按资源类型统计使用量
  - 按机构统计使用量
  - 按教师统计使用量
  - 提供使用量排行榜（热门资源 Top 10）
  - 统计数据可导出为 CSV
  - 在仪表板首页展示机构的资源使用概况
- **优先级**：P2
- **状态**：🎯 待实现
