## FR-OS-001 — API 代理服务

- **描述**：后端服务将前端的资源请求转发到 OpenSciEd 上游 API，并将响应回传给前端
- **关键特性**：
  - 提供统一的 API 入口 `/api/resource-proxy/*`
  - 将请求转发至 `openmt-api.seduino.org`
  - 在代理层添加机构 API Key 认证信息
  - 记录请求日志（不含敏感数据）
  - 支持上游 API 的所有资源类型：tutorials（教程）、courseware（课件）、hardware（硬件项目）
  - 支持列表查询、详情查询、搜索功能
  - 网络异常或上游故障时返回友好的错误响应，不导致前端白屏
  - 支持请求超时配置（默认 10 秒）
  - 支持请求重试（最多 2 次）
- **优先级**：P0
- **状态**：✅ 已实现

## FR-OS-002 — 机构集成配置

- **描述**：机构管理员可配置本机构的 OpenSciEd 集成状态和 API Key
- **关键特性**：
  - 在机构设置页面提供 OpenSciEd 集成 Tab
  - 支持启用/禁用集成（开关切换）
  - 支持输入和保存机构 API Key
  - API Key 加密存储，不回显明文到前端
  - 提供"测试连接"按钮验证 API Key 是否有效
  - 配置保存后立即生效
  - 禁用集成后，资源中心页面显示"未启用"提示
  - API Key 可重新生成（旧 Key 失效）
- **优先级**：P1
- **状态**：✅ 已实现

## FR-OS-003 — 资源中心前端

- **描述**：前端页面展示 OpenSciEd 资源，供教师浏览和使用
- **关键特性**：
  - 资源中心 Tab 页面入口
  - 支持按资源类型切换（教程 Tab / 课件 Tab / 硬件项目 Tab）
  - 资源列表以卡片形式展示（封面图、标题、简要描述、作者、更新时间）
  - 支持分页（每页 12 条）
  - 支持按关键词搜索
  - 支持按标签筛选
  - 点击卡片进入资源详情页
  - 详情页展示完整内容：标题、描述、封面、正文、附件下载
  - 资源加载失败时显示友好的空态和重试按钮
  - 教师工作台首页展示推荐资源（基于教师所授课程类型）
  - 支持收藏资源到个人收藏夹
  - 支持查看最近浏览的资源
  - 响应式布局，移动端可正常使用
- **优先级**：P0
- **状态**：✅ 已实现

## FR-OS-004 — 缓存策略

- **描述**：通过 Redis 缓存减少对上游 API 的重复请求，提升响应速度
- **关键特性**：
  - 列表接口数据缓存 30 分钟（TTL 可配置）
  - 详情接口数据缓存 60 分钟
  - 搜索结果缓存 15 分钟
  - 缓存 Key 包含：机构 ID、资源类型、分页参数、搜索参数
  - 缓存命中率可在监控面板查看
  - 机构管理员可手动清除本机构的缓存
  - 缓存过期自动失效，不影响新数据的获取
  - Redis 不可用时降级为直接请求上游
- **优先级**：P1
- **状态**：✅ 已实现

## FR-OS-005 — 资源使用统计

- **描述**：记录和展示资源的使用情况数据
- **关键特性**：
  - 记录每个资源的浏览次数
  - 记录每个资源的下载次数
  - 按资源类型统计使用量
  - 按机构统计使用量
  - 按教师统计使用量
  - 提供使用量排行榜（热门资源 Top 10）
  - 统计数据可导出为 CSV
  - 在仪表板首页展示机构的资源使用概况
- **优先级**：P2
- **状态**：🎯 待实现

## FR-OS-006 — 统一认证（双平台 JWT 共享）

- **描述**：EduInst 和 OpenMTSciEd 两个平台共享 JWT 认证，教师登录 EduInst 后，其 JWT 可被 OpenMTSciEd 识别并验证，实现"一次登录，双平台通行"
- **关键特性**：
  - 两个平台使用相同的 SECRET_KEY 签发/验证 JWT
  - OpenMTSciEd 端增加 EduInst Token 验证中间件，解析 JWT 中的 `userId`、`username`、`role`、`org_id`
  - JWT payload 中包含 `eduinst_user_id` 字段，用于在 OpenMTSciEd 中关联用户
  - 教师通过 EduInst 登录后，直接访问 OpenMTSciEd 页面时无需二次登录
  - 支持 token 过期后的优雅降级处理
  - Token 中的 `role` 为 `teacher` 时，OpenMTSciEd 自动赋予教师权限
- **优先级**：P0
- **状态**：🎯 待实现
- **涉及项目**：OpenMTEduInst（配置）、OpenMTSciEd（中间件）

## FR-OS-007 — 教师用户同步

- **描述**：当 EduInst 中创建教师或为教师分配机构时，自动在 OpenMTSciEd 中创建/关联对应的用户记录
- **关键特性**：
  - EduInst 创建教师时，通过 API 同步调用 OpenMTSciEd 的用户注册接口
  - OpenMTSciEd User 表新增字段：`eduinstUserId`（关联 EduInst 用户 ID）、`eduinstOrgId`（关联 EduInst 机构 ID）
  - 同步失败时不影响 EduInst 本地操作，记录错误日志并支持手动重试
  - 教师信息变更（姓名、邮箱等）时，同步更新 OpenMTSciEd 端
  - 教师被移除机构时，OpenMTSciEd 端标记为 `isActive=false`（不删除数据）
  - 支持批量同步：机构管理员可手动触发全量教师同步
  - 同步状态可在机构管理页面查看
- **优先级**：P0
- **状态**：🎯 待实现
- **涉及项目**：OpenMTEduInst（用户创建钩子）、OpenMTSciEd（User 模型 + API）

## FR-OS-008 — STEM教师管理模块

- **描述**：在非教育局机构（培训机构、K12学校、职业学校）的管理后台中，增加"STEM教师管理"模块，作为机构监管教师 STEM 课件活动的统一入口
- **关键特性**：
  - 在机构侧边栏菜单"STEM 教育管理"分组下增加"STEM教师管理"子菜单
  - 仅对 `training_institution`、`k12_school`、`vocational_school` 三种机构类型可见
  - `education_bureau`（教育局）不显示此菜单（教育局使用独立的监管平台）
  - 模块包含两个子页面：
    - **课件管理**：iframe 嵌入 OpenMTSciEd 课题工作室，教师可自由管理课件
    - **统计监察**：仪表盘展示机构下所有教师的课件数据
  - 机构管理员可查看所有教师的 STEM 课件概况
  - 教师角色登录后可见"课件管理"入口，但不可见"统计监察"
- **优先级**：P0
- **状态**：🎯 待实现
- **涉及项目**：OpenMTEduInst（前端菜单 + 路由）

## FR-OS-009 — 课件管理入口（iframe 嵌入）

- **描述**：教师在 EduInst 中点击"课件管理"时，通过 iframe 嵌入 OpenMTSciEd 的课题工作室页面，携带共享 JWT 实现免登录访问
- **关键特性**：
  - EduInst 后端生成带 token 的 OpenMTSciEd 深链 URL
  - 前端通过 `<iframe>` 嵌入 `https://opensciedu.matux.tech/topic-studio?token={jwt}`
  - OpenMTSciEd 端解析 URL 参数中的 token，自动完成身份识别
  - 教师在 iframe 内可自由创建、编辑、发布课件
  - 支持课件列表、详情、素材上传等完整功能
  - iframe 加载失败时显示友好的错误提示和重试按钮
  - 支持在新窗口打开（脱离 iframe 全屏使用）
  - 教师通过此入口创建的课件，机构管理员可在统计页面看到
- **优先级**：P1
- **状态**：🎯 待实现
- **涉及项目**：OpenMTEduInst（前端页面 + 后端 URL 生成）、OpenMTSciEd（token 接收 + 自动登录）

## FR-OS-010 — 统计监察仪表盘

- **描述**：机构管理员在 EduInst 中查看本机构所有教师的 STEM 课件统计数据，实现机构级监管
- **关键特性**：
  - 调用 OpenMTSciEd 统计 API 获取教师级别的课件数据
  - 统计指标包括：
    - 每位教师的课件数量（总数、本月新增）
    - 每位教师的教程数量
    - 课件总浏览量/下载量
    - 教师最近活跃时间
    - 课件审核状态（草稿/已发布/审核中）
  - 以表格形式展示，支持按指标排序
  - 支持按教师姓名搜索
  - 支持按时间范围筛选（本周/本月/本季度/自定义）
  - 提供机构级汇总数据：总课件数、总教师数、活跃教师数
  - 数据支持导出为 CSV
  - 数据每小时自动刷新，支持手动刷新
- **优先级**：P1
- **状态**：🎯 待实现
- **涉及项目**：OpenMTEduInst（前端仪表盘 + 后端代理 API）、OpenMTSciEd（教师统计 API）
