## 机构管理员角色

### US-ADMIN-OS-001 — 启用 OpenSciEd 集成

**作为**：机构管理员，**我希望**能启用 OpenSciEd 资源集成，**以便**让教师访问丰富的 STEM 教学资源。

- **验收标准**：在机构设置页面有 OpenSciEd 集成 Tab；可切换启用/禁用状态；可输入 API Key；提供"测试连接"按钮验证配置；配置保存后立即生效
- **优先级**：P1
- **关联 FR**：FR-OS-002

### US-ADMIN-OS-002 — 查看资源使用情况

**作为**：机构管理员，**我希望**能查看机构的资源使用情况，**以便**了解哪些资源最受欢迎。

- **验收标准**：在仪表板首页展示机构的资源使用概况；可查看热门资源排行榜
- **优先级**：P2
- **关联 FR**：FR-OS-005

### US-ADMIN-OS-003 — 清除资源缓存

**作为**：机构管理员，**我希望**能手动清除本机构的资源缓存，**以便**获取最新的资源数据。

- **验收标准**：在 OpenSciEd 集成设置页面有"清除缓存"按钮；点击后确认操作；清除后提示"缓存已清除"
- **优先级**：P2
- **关联 FR**：FR-OS-004

## 授课教师角色

### US-TEACHER-OS-001 — 浏览教学资源

**作为**：授课教师，**我希望**能浏览 OpenSciEd 的教学资源，**以便**找到合适的教程和课件用于备课。

- **验收标准**：在教师工作台有资源中心入口；支持按类型切换（教程/课件/硬件项目）；列表以卡片形式展示；支持分页；支持搜索和筛选
- **优先级**：P0
- **关联 FR**：FR-OS-003

### US-TEACHER-OS-002 — 查看资源详情

**作为**：授课教师，**我希望**能查看资源的完整内容，**以便**了解资源的详细信息。

- **验收标准**：点击资源卡片进入详情页；详情页展示标题、描述、封面、正文、附件；支持下载附件
- **优先级**：P0
- **关联 FR**：FR-OS-003

### US-TEACHER-OS-003 — 收藏资源

**作为**：授课教师，**我希望**能收藏我喜欢的资源，**以便**以后快速找到。

- **验收标准**：每个资源卡片和详情页有"收藏"按钮；收藏后出现在"我的收藏"列表；可取消收藏
- **优先级**：P1
- **关联 FR**：FR-OS-003

### US-TEACHER-OS-004 — 推荐资源

**作为**：授课教师，**我希望**工作台首页推荐与我所授课程相关的资源，**以便**快速找到备课所需的资料。

- **验收标准**：教师工作台首页有"推荐资源"区域；推荐基于教师所授课程类型；点击资源可查看详情
- **优先级**：P1
- **关联 FR**：FR-OS-003

### US-TEACHER-OS-005 — 搜索资源

**作为**：授课教师，**我希望**能按关键词搜索资源，**以便**快速找到特定主题的内容。

- **验收标准**：资源列表页有搜索框；输入关键词后按回车或点击搜索按钮搜索；搜索结果按相关度排序
- **优先级**：P1
- **关联 FR**：FR-OS-003

## 系统管理员角色

### US-SYSADMIN-OS-001 — 上游服务监控

**作为**：系统管理员，**我希望**能监控 OpenSciEd 上游服务的状态，**以便**及时发现和处理服务故障。

- **验收标准**：系统管理员仪表板有上游服务状态指示；展示响应时间统计；展示错误率；异常时发送告警
- **优先级**：P2
- **关联 FR**：FR-OS-001

### US-SYSADMIN-OS-002 — 缓存配置

**作为**：系统管理员，**我希望**能配置缓存策略，**以便**根据实际情况调整缓存 TTL。

- **验收标准**：有缓存配置页面；可修改列表缓存、详情缓存、搜索缓存的 TTL；配置保存后立即生效
- **优先级**：P2
- **关联 FR**：FR-OS-004

### US-SYSADMIN-OS-003 — 统一认证配置

**作为**：系统管理员，**我希望**配置 EduInst 与 OpenMTSciEd 的共享 JWT 密钥，**以便**两个平台实现统一认证。

- **验收标准**：可通过环境变量配置共享 SECRET_KEY；配置后教师登录 EduInst 的 token 可被 OpenMTSciEd 识别；配置变更后两个平台同步生效
- **优先级**：P0
- **关联 FR**：FR-OS-006

### US-SYSADMIN-OS-004 — 教师同步监控

**作为**：系统管理员，**我希望**能监控教师同步状态，**以便**及时发现和处理同步失败的情况。

- **验收标准**：有教师同步状态页面；展示同步成功/失败数量；支持手动重试失败的同步；异常时发送告警
- **优先级**：P1
- **关联 FR**：FR-OS-007

## 机构管理员角色（新增故事）

### US-ADMIN-OS-004 — 查看教师 STEM 课件统计

**作为**：机构管理员，**我希望**能在 STEM 教师管理页面查看本机构所有教师的课件统计数据，**以便**了解教师的 STEM 教学活跃度和课件质量。

- **验收标准**：STEM 教师管理页面有"统计监察"Tab；展示每位教师的课件数量、教程数量、浏览量；支持按教师搜索和排序；支持按时间范围筛选；支持导出 CSV
- **优先级**：P1
- **关联 FR**：FR-OS-010

### US-ADMIN-OS-005 — 监管教师课件内容

**作为**：机构管理员，**我希望**能查看教师创建的课件内容，**以便**进行教学质量监督和内容审核。

- **验收标准**：可查看教师的课件列表；可点击查看课件详情；可查看课件审核状态（草稿/已发布/审核中）
- **优先级**：P2
- **关联 FR**：FR-OS-010

### US-ADMIN-OS-006 — 管理教师 OpenMTSciEd 账号

**作为**：机构管理员，**我希望**创建教师时自动为其开通 OpenMTSciEd 账号，**以便**教师无需额外注册即可使用课件管理功能。

- **验收标准**：在 EduInst 创建教师时，自动在 OpenMTSciEd 创建对应账号；教师账号状态可在机构管理页面查看；支持手动触发全量同步
- **优先级**：P0
- **关联 FR**：FR-OS-007

## 授课教师角色（新增故事）

### US-TEACHER-OS-006 — 统一账号登录

**作为**：授课教师，**我希望**使用 EduInst 的账号直接访问 OpenMTSciEd 课件管理，**以便**无需记忆多个账号密码。

- **验收标准**：在 EduInst 登录后，点击"课件管理"无需二次登录；在 OpenMTSciEd 中自动识别为教师身份；token 过期后自动提示重新登录
- **优先级**：P0
- **关联 FR**：FR-OS-006

### US-TEACHER-OS-007 — 自由管理自有课件

**作为**：授课教师，**我希望**在 OpenMTSciEd 课题工作室中自由创建、编辑、发布课件，**以便**灵活管理自己的教学材料。

- **验收标准**：在 EduInst 中点击"课件管理"进入课题工作室；可创建新课件；可编辑已有课件；可上传素材（图片、文档、视频）；可发布课件供其他教师使用；可查看课件浏览量
- **优先级**：P1
- **关联 FR**：FR-OS-009

### US-TEACHER-OS-008 — 查看我的课件统计

**作为**：授课教师，**我希望**查看自己的课件使用统计数据，**以便**了解课件的受欢迎程度。

- **验收标准**：在教师工作台可查看自己的课件数量、浏览量、下载量；可看到哪些课件最受欢迎
- **优先级**：P2
- **关联 FR**：FR-OS-010
