## AC-BACKUP — 云端自动备份验收标准

### AC-BACKUP-001 — 备份策略验证

**关联 FR**：FR-BACKUP-001

1. 每日凌晨 02:00（UTC+8）系统成功触发增量备份
2. 每周日凌晨 03:00 系统成功触发全量备份
3. 备份完成后，备份列表增加一条新记录
4. 备份失败时发送告警通知

### AC-BACKUP-002 — 增量备份准确性

**关联 FR**：FR-BACKUP-002

1. 增量备份仅备份变化的数据（相对上一次备份）
2. 增量备份的大小显著小于全量备份
3. 增量备份 + 基准全量备份的还原结果与源数据一致
4. 数据校验（checksum）通过

### AC-BACKUP-003 — 一键回滚功能验证

**关联 FR**：FR-BACKUP-003, FR-BACKUP-004

1. 选择历史快照后点击"回滚至此"
2. 系统显示确认弹窗，要求二次确认
3. 回滚前自动创建安全快照
4. 回滚过程显示进度条
5. 回滚完成后系统状态恢复到快照时点
6. 回滚完成发送通知给机构管理员

### AC-BACKUP-004 — 备份状态页面

**关联 FR**：FR-BACKUP-005

1. 管理后台备份状态页面存在并可访问
2. 页面显示最近备份时间
3. 页面显示下次备份计划时间
4. 页面显示存储使用量
5. 页面显示备份结果（成功/失败）列表

### AC-BACKUP-005 — 备份存储隔离

**关联 FR**：FR-BACKUP-006

1. 各机构的备份数据物理隔离
2. A 机构管理员无法访问 B 机构的备份
3. 备份目录结构中包含 institution_id 区分
4. 对象存储中的备份按机构划分 bucket 或 prefix

### AC-BACKUP-006 — 手动备份

**关联 FR**：FR-BACKUP-007

1. 备份状态页面有"立即备份"按钮
2. 点击后系统触发一次备份
3. 手动备份在备份列表中有独立标识
4. 手动备份不被自动清理策略删除

### AC-BACKUP-007 — 保留期策略

**关联 FR**：FR-BACKUP-008

1. 增量备份 30 天后自动清理
2. 全量备份 180 天后自动清理
3. 被清理的备份从备份列表中消失
4. 被清理的备份从对象存储中删除
5. 手动备份不被清理

### AC-BACKUP-008 — 加密与完整性

**关联 FR**：FR-BACKUP-009

1. 备份文件传输时使用 TLS 加密
2. 备份文件存储时有完整性校验（如 SHA-256）
3. 还原时验证校验值，不一致时拒绝还原
4. 校验失败时记录错误日志并告警

### AC-BACKUP-009 — 监控与告警

**关联 FR**：FR-BACKUP-010

1. 备份成功/失败有独立的事件记录
2. 连续 3 次备份失败发送告警
3. 告警通过至少一种方式（站内通知 + 邮件）送达
4. 告警可在管理后台查看

## AC-AI — AI 助教能力验收标准

### AC-AI-001 — 智能排课

**关联 FR**：FR-AI-001

1. 点击"AI 排课建议"入口后，AI 在 30 秒内返回排课方案
2. 排课方案考虑教师时间、教室可用、课程类型约束
3. 排课方案可一键应用到实际排课
4. 手动微调时 AI 实时检测冲突
5. 该功能消耗 Token 可在 Token 中心查看

### AC-AI-002 — 学情分析

**关联 FR**：FR-AI-002

1. 在班级管理页面有"学情分析"入口
2. AI 生成的班级学情报告在 30 秒内返回
3. 班级报告包含出勤率、成绩趋势、薄弱知识点识别
4. 个人学员报告包含能力雷达图
5. AI 给出文字形式的改进建议
6. 识别出的高风险学员出现在"流失预警"面板
7. 该功能消耗 Token 可在 Token 中心查看

### AC-AI-003 — 代码审查

**关联 FR**：FR-AI-003

1. 在项目详情页面有"AI 代码审查"按钮
2. AI 对代码文件进行审查，返回结果在 60 秒内
3. 审查结果包含正确性、风格、逻辑、创新性四个维度
4. 每个维度有评分
5. 提供逐行注释和总结评语
6. 审查结果可保存到项目记录
7. 该功能消耗 Token 可在 Token 中心查看

### AC-AI-004 — Token 计费与管理

**关联 FR**：FR-AI-004

1. Token 中心页面可查看当前余额
2. Token 中心页面可查看充值记录
3. Token 中心页面可查看消耗分布（按功能分类）
4. Token 中心页面支持购买额外 Token 套餐
5. Token 余额不足时提示充值
6. Token 使用记录有时间戳和操作人信息

## AC-TENANT — 多租户物理隔离验收标准

### AC-TENANT-001 — 数据访问隔离

**关联 FR**：FR-TENANT-001

1. 机构 A 的用户登录后只能看到机构 A 的数据
2. 机构 A 的用户尝试访问机构 B 的数据时被拒绝
3. 数据库查询强制附加 institution_id 过滤条件
4. 数据库 schema 按机构隔离或独立 schema

### AC-TENANT-002 — 许可证管理

**关联 FR**：FR-TENANT-002, FR-TENANT-003

1. 机构试用/标准版/企业版有明确的功能差异
2. 许可证过期后非授权功能自动禁用
3. 系统管理员可手动激活/吊销许可证
4. 许可证变更后立即生效（不超过 5 分钟）

### AC-TENANT-003 — 机构资源监控

**关联 FR**：FR-TENANT-004, FR-TENANT-005

1. 系统管理员可查看各机构的资源使用量
2. 存储使用量、Token 使用量、并发连接数清晰展示
3. 超过配额时自动触发告警
4. 机构管理员可查看本机构的资源使用情况

## AC-SEC — 企业级安全防护验收标准

### AC-SEC-001 — 密码安全

**关联 FR**：FR-SEC-001

1. 用户注册时强制设置至少 12 位密码
2. 密码需包含大写、小写、数字、特殊字符中至少 3 类
3. 弱密码（如 123456、password 等）被拒绝
4. 密码采用 bcrypt 或 argon2 存储
5. 密码明文不出现在日志、请求记录中

### AC-SEC-002 — 会话与速率限制

**关联 FR**：FR-SEC-002

1. 登录失败 5 次后锁定账户 15 分钟
2. 单个 IP 1 分钟内 API 调用次数不超过 60 次
3. 超过速率限制时返回 HTTP 429
4. 会话 cookie 使用 Secure + HttpOnly + SameSite

### AC-SEC-003 — 安全监控仪表板

**关联 FR**：FR-SEC-003

1. 系统管理员可访问安全监控仪表板
2. 仪表板展示速率限制触发记录
3. 仪表板展示登录失败统计
4. 仪表板可按时间筛选
5. 仪表板可导出数据

### AC-SEC-004 — 审计日志

**关联 FR**：FR-SEC-004

1. 关键操作（创建/修改/删除用户、数据导出等）记录审计日志
2. 审计日志包含操作人、时间、操作类型、IP 地址
3. 审计日志保留 ≥ 1 年
4. 审计日志可按时间和操作类型筛选
5. 审计日志支持导出为 CSV
6. 审计日志不可被普通用户删除或修改

### AC-SEC-005 — SSL/TLS 证书管理

**关联 FR**：FR-SEC-005

1. 系统强制 HTTPS 访问
2. HTTP 请求自动重定向到 HTTPS
3. HSTS 响应头已启用
4. 证书到期前 30 天自动续期
5. 证书状态监控仪表板存在

### AC-SEC-006 — API Key 安全

**关联 FR**：NFR-SEC-005

1. 所有 API Key 仅存储于后端（环境变量或安全存储）
2. 前端 bundle 中不包含 API Key
3. API Key 在日志中自动脱敏
4. 禁止前端直接调用外部 API（必须通过后端代理）

## AC-RESOURCE — OpenSciEd 资源集成验收标准

### AC-RESOURCE-001 — 代理服务连通性

**关联 FR**：FR-RESOURCE-001

1. 后端 `/api/resource-proxy/*` 路由存在并可访问
2. 后端正确转发请求至 `openmt-api.seduino.org`
3. 响应正确透传给前端
4. 网络不通或上游服务故障时，返回友好错误，不导致前端崩溃

### AC-RESOURCE-002 — 机构配置

**关联 FR**：FR-RESOURCE-002

1. 机构可在系统设置页面找到 OpenSciEd 集成 Tab
2. 可输入 API Key
3. 可切换启用/禁用状态
4. 提供"测试连接"按钮验证配置
5. 配置保存后立即生效
6. API Key 仅在创建/更新时输入，不回显明文

### AC-RESOURCE-003 — 资源中心前端

**关联 FR**：FR-RESOURCE-003

1. 管理后台有资源中心入口
2. 资源中心页面分为教程 Tab、课件 Tab、硬件项目 Tab
3. 列表支持分页和筛选
4. 可查看资源详情（包含标题、描述、图片等）
5. 资源加载失败显示友好的空态和重试按钮
6. 资源数据通过后端代理接口获取

### AC-RESOURCE-004 — 缓存策略

**关联 FR**：FR-RESOURCE-004

1. 列表接口数据使用 Redis 缓存
2. 缓存 TTL 可配置（默认 30 分钟）
3. 缓存命中率可在监控中查看
4. 管理员可手动清除缓存

### AC-RESOURCE-005 — 教师工作台

**关联 FR**：FR-RESOURCE-005

1. 使用教师账号登录后进入教师工作台
2. 工作台界面与管理员不同，仅显示教学相关功能
3. 首页有推荐资源区域
4. 推荐资源基于教师所授课程类型
5. 点击资源可查看详情和下载
6. 教师无法访问管理后台的管理功能

## AC-WS — 多终端实时同步验收标准

### AC-WS-001 — WebSocket 连接

**关联 FR**：FR-WS-001

1. 前端登录后自动建立 WebSocket 连接
2. 连接失败自动重连（指数退避策略）
3. 连接状态在前端有可见指示（连接中/已连接/已断开）
4. WebSocket 服务部署独立于 HTTP API

### AC-WS-002 — 事件广播

**关联 FR**：FR-WS-002

1. 关键操作触发后，相关用户收到实时通知
2. 操作包括：排课变更、课时消耗、学员注册、课程完成等
3. 事件消息包含操作类型、操作人、操作时间
4. 事件不泄露敏感数据（如密码、Token）

### AC-WS-003 — 权限控制

**关联 FR**：FR-WS-003

1. WebSocket 连接建立时验证用户身份和机构
2. 事件广播基于用户角色和机构过滤
3. 机构 A 的用户不会收到机构 B 的事件
4. 教师不会收到系统管理员级别的事件

### AC-WS-004 — 离线消息队列

**关联 FR**：FR-WS-004

1. 用户离线期间的事件被缓存
2. 用户重新连接后自动获取离线期间的事件
3. 离线消息有时间窗口（默认 7 天）
4. 超过时间窗口的消息被清理

### AC-WS-005 — 移动端体验

**关联 FR**：FR-WS-005

1. 移动端浏览器访问系统有响应式布局
2. 主要功能在移动端可用（学员管理、课程查看、排课查看等）
3. 移动端离线操作后联网自动同步
4. 关键操作（如排课变更）有推送通知
