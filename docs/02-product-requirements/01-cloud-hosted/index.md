## 产品愿景

OpenMT 云托管版是专为 STEM 教育机构打造的 SaaS 管理平台，面向不具备 IT 运维能力但希望专注于教学业务的培训机构、K12 学校及职业学校，提供**免运维、高可用、智能化**的一站式教育管理解决方案。

---

## 核心价值

1. **开箱即用** — 注册即可使用，无需服务器、数据库、运维团队
2. **STEM 专属** — 硬件设备管理、实验项目管理、Token 计费、创客空间调度等差异化功能
3. **数据安全** — 企业级 SSL/TLS 加密、多租户物理隔离、符合教育行业合规标准
4. **智能驱动** — 云端大模型赋能的 AI 助教、智能排课、学情分析
5. **多端同步** — Web / 平板 / 手机端数据秒级同步，随时随地管理

---

## 与开源社区版的关系

云托管版是在开源社区版基础上的**增值服务层**，二者共享同一套代码基座，通过许可证（License）和功能开关（Feature Flag）实现差异化控制。

**实现状态**：✅ 许可证体系和功能开关已在后端完整实现（LicenseType 枚举含 7 种类型、TenantFeatureFlag 模型和 TenantInitService 均已落地）；前端 Angular 路由守卫尚未实现。

| 维度 | 开源社区版 | 云托管版 |

| **创客空间预约** | ✅ | ✅ |

| **竞赛认证** | ✅ | ✅ |
| **教学资源库** | ✅ | ✅ |
| **营销中心** | ✅ | ✅ |
| **财务结算** | ✅ | ✅ |
| **消息中心** | ✅ | ✅ |

| **自动升级** | ❌（手动更新） | ✅ 无感热更新 |

## 功能模块总览

### 基础管理功能（两版本共有）

以下功能在开源社区版和云托管版中均可使用：

| 功能模块 | 涉及 API |
|---------|---------|
| 硬件设备管理 | `/api/v1/hardware/*` |
| Token 计费系统 | `/api/v1/token/*` |
| 创客空间预约 | `/api/v1/space/*` |
| 学员管理 | `/api/v1/students/*` |
| 智能排课 | `/api/v1/schedules/*` |
| 项目管理 | `/api/v1/projects/*` |
| 竞赛认证 | `/api/v1/competitions/*` |
| 教学资源库 | `/api/v1/resources/*` |
| 营销中心 | `/api/v1/marketing/*` |
| 财务结算 | `/api/v1/finance/*` |
| 消息中心 | `/api/v1/notifications/*` |

### 云托管专属功能

以下功能仅在云托管版（LicenseType: `CLOUD_HOSTED`）中开启：

| 功能模块 | 说明 | 实现状态 |
|---------|------|---------|
| **云端自动备份** | 自动备份、一键回滚、保留策略 | ✅ 数据模型 + API 完成；定时调度待实现 |
| **高级 AI 助教** | 智能排课、学情分析、代码审查 | ✅ 服务 + API 完成；真实模型接入待实现 |
| **多租户物理隔离** | Schema 级数据隔离、缓存隔离 | ✅ 行级隔离完成；Schema 级待实现 |
| **企业级安全防护** | JWT 认证、速率限制、审计日志 | ✅ 基础防护完成；WAF / 数据脱敏待实现 |
| **OpenSciEd STEM 资源集成** | 教程、课件、硬件项目代理接入 | ✅ M1–M3 完成 |
| **多端实时同步** | WebSocket 推送、响应式布局 | ✅ 基础推送完成；PWA 待实现 |
