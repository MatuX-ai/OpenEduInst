## 机构管理员角色

### US-ADMIN-001 — 备份状态查看

**作为**机构管理员，**我希望**能在管理后台查看备份状态，**以便**了解数据是否安全，最新备份时间，以及存储使用情况。

- **验收标准**：在管理后台有独立的备份状态页面，显示最近备份时间、下次备份计划、存储使用量、备份结果（成功/失败）
- **优先级**：P1
- **关联 FR**：FR-BACKUP-005

### US-ADMIN-002 — 一键回滚

**作为**机构管理员，**我希望**能在出现数据问题时一键回滚至历史快照，**以便**快速恢复业务正常运行。

- **验收标准**：在历史快照列表中，每个快照都有"回滚至此"按钮；回滚前有确认弹窗；回滚前自动创建安全快照；回滚过程显示进度条；回滚完成发送通知
- **优先级**：P0
- **关联 FR**：FR-BACKUP-003, FR-BACKUP-004, FR-BACKUP-010

### US-ADMIN-003 — 手动备份

**作为**机构管理员，**我希望**能在进行重大操作前手动触发一次备份，**以便**为数据提供安全保障。

- **验收标准**：在备份状态页面有"立即备份"按钮；手动备份有独立标识（manual），不被自动清理
- **优先级**：P2
- **关联 FR**：FR-BACKUP-007

### US-ADMIN-004 — AI 助教功能使用

**作为**机构管理员/教务主管，**我希望**能使用 AI 助教功能，**以便**获得智能的排课建议、学情分析和代码审查能力。

- **验收标准**：在管理后台有 AI 助教入口；智能排课功能可生成优化后的排课方案；学情分析可查看学员能力雷达图和建议；代码审查可对项目代码进行评分和建议；每次功能使用有 Token 消耗记录
- **优先级**：P1
- **关联 FR**：FR-AI-001, FR-AI-002, FR-AI-003

### US-ADMIN-005 — Token 余额管理

**作为**机构管理员，**我希望**能查看 Token 余额和消耗记录，**以便**控制 AI 功能的使用成本。

- **验收标准**：在管理后台有 Token 中心页面；显示当前余额、充值记录、消耗分布（按功能）；支持购买额外 Token 套餐
- **优先级**：P0
- **关联 FR**：FR-AI-004

### US-ADMIN-006 — 教学资源浏览

**作为**机构管理员/教师，**我希望**能在管理后台浏览 OpenSciEd 的教学资源，**以便**为课程准备找到合适的教程和课件。

- **验收标准**：在管理后台有资源中心入口；支持按 Tab 切换教程、课件、硬件项目；支持分页和筛选；支持查看资源详情；资源加载失败有友好提示和重试按钮
- **优先级**：P0
- **关联 FR**：FR-RESOURCE-003

### US-ADMIN-007 — OpenSciEd 集成配置

**作为**机构管理员，**我希望**能配置机构的 OpenSciEd 集成，**以便**启用/禁用资源访问并管理 API Key。

- **验收标准**：在系统设置页面有 OpenSciEd 集成 Tab；可输入 API Key；可切换启用/禁用状态；提供"测试连接"按钮验证配置；配置保存后立即生效
- **优先级**：P1
- **关联 FR**：FR-RESOURCE-002

### US-ADMIN-008 — 学员流失预警

**作为**机构管理员，**我希望** AI 助功能自动识别即将流失的学员，**以便**及时采取措施，提升学员留存。

- **验收标准**：在学员管理或仪表盘页面有"流失预警"面板；显示预警学员列表；显示预警原因（出勤率、课时消耗等）
- **优先级**：P2
- **关联 FR**：FR-AI-002

### US-ADMIN-009 — 多终端数据同步

**作为**机构管理员，**我希望**在 PC、平板、手机上操作的数据能实时同步，**以便**在任意设备继续工作。

- **验收标准**：在设备 A 操作的数据，设备 B 刷新立即看到；关键操作（如排课变更）有推送通知；移动端离线操作后联网自动同步
- **优先级**：P1
- **关联 FR**：FR-WS-001, FR-WS-002, FR-WS-005

## 授课教师角色

### US-TEACHER-001 — 教师工作台访问

**作为**授课教师，**我希望**能有独立的教师工作台界面，**以便**专注于教学相关操作。

- **验收标准**：使用教师账号登录后进入教师工作台；工作台界面与管理员不同，仅显示教学相关功能；菜单按角色过滤，教师无法访问管理功能
- **优先级**：P1
- **关联 FR**：FR-RESOURCE-005

### US-TEACHER-002 — 教学资源推荐

**作为**授课教师，**我希望**工作台首页能推荐相关的教学资源，**以便**快速找到备课所需的教程和课件。

- **验收标准**：教师工作台首页有推荐资源区域；推荐基于所授课程类型；点击资源可查看详情和下载
- **优先级**：P1
- **关联 FR**：FR-RESOURCE-003, FR-RESOURCE-005

### US-TEACHER-003 — 学生代码审查

**作为**授课教师，**我希望**能用 AI 助功能快速审查学生的编程项目，**以便**提供详细的代码质量和改进建议。

- **验收标准**：在项目详情页面有"AI 代码审查"按钮；审查结果显示代码正确性、风格、逻辑、创新性四个维度的评分；提供逐行注释和总结评语
- **优先级**：P1
- **关联 FR**：FR-AI-003

### US-TEACHER-004 — 学情分析报告

**作为**授课教师，**我希望**能查看班级和个人的学情分析报告，**以便**了解学生的学习情况和能力成长。

- **验收标准**：在班级管理页面有"学情分析"入口；可查看班级整体学情报告；可查看学员个人学情报告（雷达图+文字建议）
- **优先级**：P1
- **关联 FR**：FR-AI-002

### US-TEACHER-005 — 排课智能建议

**作为**授课教师，**我希望**排课时 AI 能提供智能建议，**以便**优化课程安排，避免冲突。

- **验收标准**：在排课管理页面有"AI 排课建议"入口；AI 基于教师、教室、时间约束生成优化方案；支持手动微调，AI 实时检测冲突
- **优先级**：P1
- **关联 FR**：FR-AI-001

## 家长/学员角色

### US-PARENT-001 — 学习进度查看

**作为**家长/学员，**我希望**能在管理端查看学习进度，**以便**了解课时消耗和课程完成情况。

- **验收标准**：家长登录后可查看学员课程进度；显示剩余课时；显示已完成课程列表；显示下次上课时间
- **优先级**：P0
- **关联 FR**：（培训平台核心功能）

### US-PARENT-002 — 续费提醒

**作为**家长/学员，**我希望**在课时不足时收到续费提醒，**以便**及时续费保证学习不中断。

- **验收标准**：剩余课时 ≤ 10 课时时，系统自动推送续费通知；管理端显示续费入口
- **优先级**：P1
- **关联 FR**：（培训平台核心功能）

### US-PARENT-003 — 作品成果查看

**作为**家长/学员，**我希望**能查看学员的项目作品和竞赛成果，**以便**展示孩子的学习成果。

- **验收标准**：有"我的作品"展示页面；作品含图片、说明、技术栈；作品状态（进行中/已完成）清晰标识
- **优先级**：P2
- **关联 FR**：（培训平台核心功能）

## 系统管理员角色

### US-SYSADMIN-001 — 多租户管理

**作为**系统管理员，**我希望**能管理所有机构租户，**以便**监控系统整体运行状况。

- **验收标准**：系统管理员有独立的管理控制台；可查看各机构租户列表；可查看各机构的资源使用量；可查看各机构的许可证状态
- **优先级**：P0
- **关联 FR**：FR-TENANT-001, FR-TENANT-004, FR-TENANT-005

### US-SYSADMIN-002 — 系统安全监控

**作为**系统管理员，**我希望**能监控系统安全状态，**以便**及时发现并响应安全事件。

- **验收标准**：安全监控仪表板；查看速率限制触发记录；查看审计日志；支持按时间和操作类型筛选日志；支持日志导出为 CSV
- **优先级**：P1
- **关联 FR**：FR-SEC-003, FR-SEC-004

### US-SYSADMIN-003 — SSL 证书管理

**作为**系统管理员，**我希望**系统能自动管理 SSL/TLS 证书，**以便**保证 HTTPS 加密传输的可靠性。

- **验收标准**：证书到期前 30 天自动续期；有证书状态监控仪表板；支持多域名证书配置
- **优先级**：P1
- **关联 FR**：FR-SEC-005

### US-SYSADMIN-004 — 许可证管理

**作为**系统管理员，**我希望**能管理各机构的许可证，**以便**控制不同机构的功能权限和有效期。

- **验收标准**：可查看各机构的许可证类型和有效期；可手动激活/吊销许可证；可设置许可证功能开关
- **优先级**：P0
- **关联 FR**：（许可证体系）
