## FR-BACKUP — 云端自动备份

### 功能概述

为机构数据提供全自动、零运维的备份保护，确保数据安全不丢失。

**当前实现状态**：✅ 备份数据模型已建立（BackupSnapshot / RestoreOperation）；✅ 备份服务已实现（CloudBackupService）；✅ RESTful API 已注册（`/api/v1/cloud/backup/*`）；✅ 保留策略已实现（每日增量 30 天 + 每周全量 12 周）；✅ 回滚前自动创建安全快照已实现；✅ 过期快照清理逻辑已实现；🎯 定时调度（Celery Beat）待实现；🎯 实际 S3/MinIO 上传待实现；🎯 每月备份恢复演练待实现；🎯 备份成功/失败通知推送待实现。

### FR-BACKUP-001 — 自动备份策略

- **描述**：系统自动按预设策略为每个机构创建数据备份
- **规格**：每日凌晨 02:00（UTC+8）自动执行增量备份；每周日凌晨 03:00 执行一次全量备份
- **优先级**：P0
- **状态**：🎯 待实现（定时调度）

### FR-BACKUP-002 — 快照保留策略

- **描述**：自动管理备份快照的生命周期，平衡存储成本与数据安全性
- **规格**：保留最近 30 天的每日增量快照 + 最近 12 周的每周全量快照；过期快照自动清理
- **优先级**：P0
- **状态**：✅ 已实现

### FR-BACKUP-003 — 一键回滚

- **描述**：管理员可通过管理界面将机构数据回滚至任意历史快照时间点
- **规格**：选择目标快照 → 确认弹窗 → 执行恢复 → 进度条 → 完成通知；全量恢复 ≤ 30 分钟，增量恢复 ≤ 10 分钟
- **优先级**：P0
- **状态**：✅ API 已完成；🎯 前端界面待完善

### FR-BACKUP-004 — 回滚安全快照

- **描述**：执行数据回滚前，自动创建当前状态的安全快照，防止回滚后数据丢失
- **规格**：回滚操作触发前，自动生成带 `safe_rollback_` 前缀的快照；安全快照保留 30 天
- **优先级**：P1
- **状态**：✅ 已实现

### FR-BACKUP-005 — 备份状态看板

- **描述**：显示最近备份时间、下次备份计划、备份存储空间使用量
- **规格**：看板包含：最近备份时间、下次备份计划时间、存储使用量（GB）、备份状态（成功/失败/进行中）
- **优先级**：P1
- **状态**：🎯 待实现

### FR-BACKUP-006 — 历史快照列表

- **描述**：按时间倒序显示所有可用快照，支持按日期筛选
- **规格**：列表项包含：快照时间、快照类型（全量/增量）、数据大小、操作按钮
- **优先级**：P1
- **状态**：✅ 已实现

### FR-BACKUP-007 — 手动备份

- **描述**：管理员可随时触发一次即时备份
- **规格**：手动备份标记为 `manual` 类型，不受自动清理策略限制，永久保留 1 份
- **优先级**：P2
- **状态**：✅ 已实现

### FR-BACKUP-008 — 备份通知

- **描述**：备份成功/失败推送通知至管理员邮箱和站内信
- **规格**：成功通知包含快照时间和数据大小；失败通知包含错误码和建议操作
- **优先级**：P2
- **状态**：🎯 待实现

### FR-BACKUP-009 — 备份恢复演练

- **描述**：每月自动执行一次备份恢复演练，验证备份数据完整性
- **规格**：选择最近一份全量快照，在隔离环境中恢复，执行数据校验，生成演练报告
- **优先级**：P2
- **状态**：🎯 待实现

### FR-BACKUP-010 — 回滚权限控制

- **描述**：回滚操作需超级管理员或机构管理员确认，记录审计日志
- **规格**：审计日志包含：操作人、时间、目标快照信息、IP 地址、操作结果
- **优先级**：P1
- **状态**：✅ 已实现

## FR-AI — 高级 AI 助教

### 功能概述

集成云端大模型，为教师和管理员提供智能化教学辅助和运营决策支持。

**当前实现状态**：✅ AI 助教服务已实现（AIAssistantService）；✅ RESTful API 已注册（`/api/v1/ai/*`）；✅ 三大子功能基础版完成（智能排课、学情分析、代码审查）；✅ Token 消耗计费已集成；🎯 遗传算法优化排课待实现；🎯 接入真实大模型 API 待实现。

### FR-AI-001 — 智能排课建议

- **描述**：基于历史排课数据和约束条件，为教务主管提供智能排课方案
- **规格**：输入：教师列表、教室列表、课程列表、时间约束、历史排课数据；输出：最优排课方案（冲突最少、负载均衡、教室利用率最高）；算法：约束满足 + 贪心优化（✅ 已实现）；规划升级：约束满足 + 遗传算法的多目标优化（🎯 待实现）；交互：生成方案后，支持手动微调，AI 实时检测冲突并给出替代建议
- **Token 消耗**：每次排课建议约消耗 500-2000 Token（取决于课程规模）
- **优先级**：P1
- **状态**：✅ 基础版已实现

### FR-AI-002 — 学生学情分析

- **描述**：为每位学员生成个性化学情报告，包含能力评估和改进建议
- **规格**：分析维度：出勤率、课时消耗速度、项目完成率、竞赛获奖、能力评估；输出格式：个人学情报告（雷达图 + 趋势图 + 文字建议）；预警机制：识别"即将流失"学员，推送预警；群体分析：班级整体学情报告、教师教学质量对比分析
- **Token 消耗**：每份个人报告约 300 Token，班级报告约 800 Token
- **优先级**：P1
- **状态**：✅ 已实现

### FR-AI-003 — 代码自动审查

- **描述**：对学员提交的项目代码进行自动审查，给出评分和改进建议
- **规格**：支持语言：Python、C/C++（Arduino）、JavaScript、Scratch 伪代码；审查内容：语法错误、逻辑漏洞、代码风格、性能建议、安全提醒；评分体系：代码正确性（40%）+ 代码风格（20%）+ 逻辑结构（20%）+ 创新性（20%）；反馈格式：逐行注释 + 总结评语 + 改进建议
- **Token 消耗**：每次审查约 200-500 Token（取决于代码长度）
- **优先级**：P1
- **状态**：✅ 已实现

### FR-AI-004 — AI Token 额度管理

- **描述**：管理机构的 AI Token 余额和消耗记录
- **规格**：云托管版每月赠送 10,000 Token；超出部分按 ¥0.01/Token 计费；可通过 Token 中心购买额外套餐；显示 Token 余额、充值记录、消耗分布（按功能分类）
- **优先级**：P0
- **状态**：✅ 已实现

### FR-AI-005 — 大模型接入配置

- **描述**：提供云端大模型 API 的接入配置和调用接口
- **规格**：支持可配置的模型提供商；模型参数（temperature、max_tokens）可调整；调用失败降级为基础规则引擎
- **优先级**：P2
- **状态**：🎯 待实现

## FR-TENANT — 多租户物理隔离

### 功能概述

确保不同机构的数据在物理层面完全隔离，杜绝数据泄露风险。

**当前实现状态**（行级过滤模式）：✅ 多租户隔离中间件已实现（TenantIsolationMiddleware）；✅ 从 JWT Token 提取 `org_id` 注入 `request.state`，路由层通过 `filter(Model.org_id == org_id)` 做行级过滤；✅ 所有业务路由均使用 `require_org_context` 依赖强制校验组织上下文；✅ 审计日志中间件记录所有请求的 org_id/user_id/IP；🎯 PostgreSQL Schema 级隔离待实现；🎯 Redis Key 前缀隔离待实现；🎯 S3/MinIO Bucket 级隔离待实现。

### FR-TENANT-001 — 数据库 Schema 级隔离

- **描述**：每个机构在 PostgreSQL 中拥有独立的 Schema，表结构相同但数据完全物理隔离
- **规格**：租户创建时自动创建 Schema；所有查询自动路由至对应 Schema；Schema 命名规则：`org_[org_id]`
- **优先级**：P0
- **状态**：🎯 待实现（当前为行级 org_id 过滤）

### FR-TENANT-002 — Redis Key 前缀隔离

- **描述**：缓存数据按机构隔离，防止不同机构的缓存数据交叉
- **规格**：Redis Key 格式：`{org_id}:{module}:{key}`；租户注销时自动清理对应缓存
- **优先级**：P1
- **状态**：🎯 待实现

### FR-TENANT-003 — 文件存储 Bucket 级隔离

- **描述**：S3/MinIO 对象存储按机构隔离，每个机构拥有独立的存储桶或前缀
- **规格**：文件路径前缀：`/org-{org-id}/...`；支持独立的生命周期策略
- **优先级**：P1
- **状态**：🎯 待实现

### FR-TENANT-004 — 组织上下文强制校验

- **描述**：所有 API 请求必须携带有效的组织上下文，防止越权访问
- **规格**：使用 `require_org_context` 依赖强制校验；无有效 org_id 的请求返回 403；审计日志记录每次请求的 org_id、user_id、IP
- **优先级**：P0
- **状态**：✅ 已实现

### FR-TENANT-005 — 跨机构访问防护

- **描述**：用户只能访问所属机构的数据，跨机构访问返回 403 Forbidden
- **规格**：基于 JWT Token 中的 org_id 与请求数据的 org_id 比对；不一致返回 403 + 审计日志记录
- **优先级**：P0
- **状态**：✅ 已实现

## FR-SEC — 企业级安全防护

### 功能概述

提供企业级的安全防护体系，保护机构和学员数据安全。

**当前实现状态**：✅ JWT Token + Refresh Token 双 Token 认证已实现；✅ RBAC 角色权限 + 数据级隔离已实现；✅ 速率限制中间件已实现；✅ 审计日志中间件已实现（记录至 logs/audit.log）；✅ HSTS / X-Content-Type-Options / X-Frame-Options / Referrer-Policy 安全响应头已配置；✅ Demo 模式只读中间件已实现；🎯 SSL/TLS 证书自动签发（Let's Encrypt）待实现；🎯 敏感字段 AES-256 加密存储待实现；🎯 XSS CSP Header 待实现；🎯 数据脱敏显示待实现。

### FR-SEC-001 — 双 Token 认证机制

- **描述**：使用 JWT Access Token + Refresh Token 实现安全的用户认证
- **规格**：Access Token 有效期 2 小时；Refresh Token 有效期 7 天；支持 Token 黑名单机制；Token 刷新自动续期
- **优先级**：P0
- **状态**：✅ 已实现

### FR-SEC-002 — RBAC 角色权限模型

- **描述**：基于角色的访问控制，支持细粒度权限管理
- **规格**：预置角色：超级管理员、机构管理员、教务主管、授课教师、招生顾问、家长/学员；支持自定义角色和权限分配；数据级隔离：用户仅能访问所属机构的数据
- **优先级**：P0
- **状态**：✅ 已实现

### FR-SEC-003 — 速率限制（防暴力破解/CC 攻击）

- **描述**：对 API 请求实施速率限制，防止暴力破解和 CC 攻击
- **规格**：普通接口 100 次/分钟/IP；敏感接口（登录、密码重置）10 次/分钟/IP；超出限制返回 429 Too Many Requests + Retry-After 响应头
- **优先级**：P0
- **状态**：✅ 已实现

### FR-SEC-004 — 审计日志

- **描述**：记录所有关键操作，支持追溯和合规审计
- **规格**：记录内容：操作人、时间、IP、操作类型、操作结果、数据变更（可选）；日志保留 ≥ 1 年；支持日志导出为 CSV；支持按时间、操作人、操作类型搜索筛选
- **优先级**：P1
- **状态**：✅ 已实现

### FR-SEC-005 — SSL/TLS 证书自动管理

- **描述**：使用 Let's Encrypt 自动签发和续期 HTTPS 证书
- **规格**：证书到期前 30 天自动续期；证书状态监控看板；支持多域名证书
- **优先级**：P1
- **状态**：🎯 待实现

### FR-SEC-006 — 敏感数据加密存储

- **描述**：手机号、身份证号等敏感字段使用 AES-256 加密存储
- **规格**：加密密钥使用 KMS 管理，独立于应用代码；支持按字段级别配置加密策略；导出数据时自动脱敏
- **优先级**：P1
- **状态**：🎯 待实现

### FR-SEC-007 — 数据脱敏显示

- **描述**：敏感信息在界面显示时自动脱敏，保护用户隐私
- **规格**：手机号显示为 `138****5678`；身份证号显示为 `1101****1234`；邮箱显示为 `us***@example.com`；权限控制：仅授权角色可查看完整信息
- **优先级**：P1
- **状态**：🎯 待实现

### FR-SEC-008 — 安全响应头

- **描述**：配置标准的 Web 安全响应头
- **规格**：HSTS（Strict-Transport-Security）；X-Content-Type-Options；X-Frame-Options；Referrer-Policy；Content-Security-Policy（CSP）
- **优先级**：P1
- **状态**：✅ 基础已完成；🎯 CSP 待实现

### FR-SEC-009 — SQL 注入防护

- **描述**：使用 ORM 参数化查询，禁止原生 SQL 拼接
- **规格**：所有数据库操作通过 SQLAlchemy ORM 执行；代码审查禁止拼接字符串的 SQL 语句
- **优先级**：P0
- **状态**：✅ 已实现

### FR-SEC-010 — XSS 防护

- **描述**：前端输入过滤 + CSP Header 配置，防止跨站脚本攻击
- **规格**：用户输入自动 HTML 转义；富文本内容使用白名单过滤；CSP Header 限制脚本来源
- **优先级**：P1
- **状态**：🎯 待实现

## FR-RESOURCE — OpenSciEd STEM 资源集成

### 功能概述

云托管版通过 EduInst 后端代理接入 OpenSciEd 平台，为机构管理员与授课教师提供教程、课件、硬件项目等 STEM 数字资源，与机构物理设备台账职责分离。

**当前实现状态**：✅ 组织模型已预留 openscied_* 字段；✅ 环境变量已配置；✅ 数据库迁移脚本已提供；✅ M1 已交付（后端代理、前端 OpenMtSciEdService、单元测试与联调脚本）；✅ M3 已交付（教师工作台、角色守卫、菜单过滤、系统设置集成 Tab）；✅ M6 已交付（@openmt/scied-ui 共享 Angular 组件库）；🎯 课题工作室 SSO 免登待实现。

### FR-RESOURCE-001 — API 代理服务

- **描述**：提供 `/api/v1/openscied/tutorials|coursewares|hardware-projects|stats|health` 等代理接口
- **规格**：所有代理路由需 `require_org_context`；未启用集成时返回 403 + 错误码 `OPENSCIED_DISABLED`；上游超时/5xx 返回 502 + 可读 message；响应中 `file_url`/`thumbnail_url` 经 CDN 规范化
- **优先级**：P0
- **状态**：✅ 已实现（M1）

### FR-RESOURCE-002 — 机构集成配置

- **描述**：支持机构独立配置 OpenSciEd API Key 和启用状态
- **规格**：`GET /api/v1/openscied/config` 返回启用状态、同步状态、掩码 Key；`PUT /api/v1/openscied/config` 管理员更新开关与 Key；系统设置页提供 OpenSciEd 集成 Tab；提供"测试连接"按钮调用 `/openscied/health`
- **优先级**：P1
- **状态**：✅ 已实现（M3）

### FR-RESOURCE-003 — 前端教学资源浏览

- **描述**：在机构管理界面提供 STEM 资源浏览功能
- **规格**：OpenMtSciEdService 调用 EduInst 代理而非直连 SciEd；教学资源页面移除 Mock 数据；提供 Tab 切换：教程、课件、硬件项目；支持分页 + 学科/年级筛选；资源详情侧栏展示；加载失败空态 + 重试按钮；集成未启用时显示引导文案
- **优先级**：P0
- **状态**：✅ 已实现（M1-M2）

### FR-RESOURCE-004 — 仪表盘资源入口

- **描述**：在培训仪表盘中添加资源卡片，支持点击跳转至资源库
- **规格**：`training-dashboard-v2` 资源卡片可点击跳转 `/resources`；资源描述数字来自 `/openscied/stats`；K12 仪表盘"素材库"跳转至教程 Tab
- **优先级**：P1
- **状态**：✅ 已实现（M2）

### FR-RESOURCE-005 — 教师工作台

- **描述**：为授课教师提供独立的工作台界面

## FR-WS — 多端实时同步

### 功能概述

云托管版数据在 Web、平板、手机端秒级同步，确保所有终端数据一致。

**当前实现状态**：✅ WebSocket 实时推送服务已实现（ConnectionManager）；✅ WebSocket 端点已注册（`/api/v1/ws/connect`）；✅ 支持按 org_id 分组广播、指定用户推送、连接统计；✅ 支持事件类型：排课变更、学员签到、续费预警、系统公告、备份完成、支付确认；✅ 前端响应式布局已通过 Angular Material 支持（桌面 1280px+ / 平板 768-1024px / 移动 <768px）；🎯 PWA 离线支持待实现；🎯 30s 轮询准实时数据待实现；🎯 移动端离线缓存自动同步待实现。

### FR-WS-001 — WebSocket 实时推送

- **描述**：通过 WebSocket 实现服务器主动推送数据变更
- **规格**：按 org_id 分组广播，确保仅推送至对应机构的在线用户；支持指定用户的定向推送；支持连接统计（在线用户数、活跃连接数）
- **事件类型**：排课变更、学员签到、续费预警、系统公告、备份完成、支付确认
- **优先级**：P0
- **状态**：✅ 已实现

### FR-WS-002 — 响应式多终端适配

- **描述**：系统适配桌面、平板、手机三种屏幕尺寸
- **规格**：桌面端（≥1280px）：完整功能布局，支持多窗口操作；平板端（768-1024px）：优化触控操作，适度简化布局；移动端（<768px）：核心功能优先，底部导航栏；使用 Angular Material + Flex Layout 实现
- **优先级**：P0
- **状态**：✅ 已实现

### FR-WS-003 — PWA 离线支持

- **描述**：将 Web 应用封装为 PWA，支持离线查看缓存数据
- **规格**：支持安装至设备主屏幕；离线可查看已缓存数据；联网后自动同步变更；使用 Service Worker 实现
- **优先级**：P2
- **状态**：🎯 待实现

### FR-WS-004 — 准实时轮询（降级方案）

- **描述**：对非关键数据使用 30 秒轮询，作为 WebSocket 的降级方案
- **规格**：营收统计、消课率、设备使用率等准实时数据；WebSocket 连接失败时自动降级至轮询
- **优先级**：P2
- **状态**：🎯 待实现

### FR-WS-005 — 移动端离线缓存自动同步

- **描述**：移动端在离线状态下操作的数据，联网后自动与服务器同步
- **规格**：使用本地 IndexedDB 存储离线操作记录；联网后自动执行冲突检测和数据合并；冲突时提示用户手动选择
- **优先级**：P3
- **状态**：🎯 待实现
