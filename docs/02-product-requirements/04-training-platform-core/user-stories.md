## 系统管理员角色

### US-SYSADMIN-CORE-001 — 机构管理

**作为**：系统管理员，**我希望**能创建和管理机构租户，**以便**管理系统中的各个教育机构。

- **验收标准**：可创建新机构，输入机构名称、联系方式、许可证类型；可查看所有机构列表；可管理机构许可证（激活/吊销/延期）；可查看各机构的资源使用情况
- **优先级**：P0
- **关联 FR**：FR-CORE-02

### US-SYSADMIN-CORE-002 — 安全监控

**作为**：系统管理员，**我希望**能查看系统的安全状态和登录日志，**以便**及时发现异常情况。

- **验收标准**：有安全监控仪表板；展示登录失败统计；展示速率限制触发记录；支持按时间筛选日志；支持导出日志数据
- **优先级**：P1
- **关联 FR**：FR-CORE-01

### US-SYSADMIN-CORE-003 — 许可证模板管理

**作为**：系统管理员，**我希望**能定义不同版本的许可证模板，**以便**为机构提供不同等级的服务。

- **验收标准**：可定义试用版/标准版/企业版的功能差异；可设置各版本的资源配额（学员数上限、存储配额、Token 配额）；可设置许可证有效期
- **优先级**：P1
- **关联 FR**：FR-CORE-02

## 机构管理员角色

### US-ADMIN-CORE-001 — 添加新学员

**作为**：机构管理员，**我希望**能添加新学员，**以便**将新报名的学员录入系统。

- **验收标准**：在学员管理页面有"添加学员"按钮；表单包含学员基本信息和家长信息；支持批量导入（Excel）；添加成功后学员出现在列表中
- **优先级**：P0
- **关联 FR**：FR-CORE-03

### US-ADMIN-CORE-002 — 为学员报名课程

**作为**：机构管理员，**我希望**能为学员报名课程，**以便**完成课程报名流程并分配课时。

- **验收标准**：在学员详情页面有"报名课程"入口；可选择课程和班级；自动创建订单记录；课时余额正确更新
- **优先级**：P0
- **关联 FR**：FR-CORE-03, FR-CORE-05, FR-CORE-07

### US-ADMIN-CORE-003 — 创建课程产品

**作为**：机构管理员，**我希望**能创建课程产品，**以便**定义机构提供的课程服务。

- **验收标准**：在课程管理页面有"添加课程"入口；可设置课程名称、类型、课时数、学费、课程描述；支持设置课程大纲
- **优先级**：P0
- **关联 FR**：FR-CORE-05

### US-ADMIN-CORE-004 — 创建班级

**作为**：机构管理员，**我希望**能创建和管理班级，**以便**组织学员进行学习。

- **验收标准**：在班级管理页面有"添加班级"入口；可设置班级名称、所属课程、开课时间、结束时间、授课教师；可查看班级学员列表
- **优先级**：P0
- **关联 FR**：FR-CORE-05

### US-ADMIN-CORE-005 — 机构信息管理

**作为**：机构管理员，**我希望**能管理机构的基本信息，**以便**展示机构的信息。

- **验收标准**：可编辑机构名称、Logo、联系方式、地址；更改生效后全站同步显示
- **优先级**：P1
- **关联 FR**：FR-CORE-02

### US-ADMIN-CORE-006 — 角色和权限分配

**作为**：机构管理员，**我希望**能为员工分配角色和权限，**以便**控制不同用户的访问范围。

- **验收标准**：可创建员工账号；可为员工分配角色（教务主管、教师、财务等）；角色权限清晰定义；权限变更实时生效
- **优先级**：P1
- **关联 FR**：FR-CORE-01

## 教务主管角色

### US-OPERATOR-CORE-001 — 排课管理

**作为**：教务主管，**我希望**能方便地管理课程表和排课，**以便**高效安排教师和教室。

- **验收标准**：在排课管理页面可查看周视图/月视图课程表；支持拖拽调整课程时间；可分配教师和教室；自动检测时间冲突
- **优先级**：P0
- **关联 FR**：FR-CORE-06

### US-OPERATOR-CORE-002 — 调课和通知

**作为**：教务主管，**我希望**能调整课程安排并自动通知相关人员，**以便**灵活应对临时变更。

- **验收标准**：在课程表中可选择课程并调整时间/教师/教室；调课后自动发送通知给相关学员和家长；调课记录可查看
- **优先级**：P1
- **关联 FR**：FR-CORE-06, FR-CORE-09

### US-OPERATOR-CORE-003 — 课时消耗管理

**作为**：教务主管，**我希望**能记录和管理学员的课时消耗，**以便**及时提醒续费。

- **验收标准**：在学员详情页面可查看课时余额和消耗记录；上课后课时自动扣减；课时余额不足时显示续费提醒
- **优先级**：P0
- **关联 FR**：FR-CORE-03

### US-OPERATOR-CORE-004 — 考勤管理

**作为**：教务主管，**我希望**能记录学员的考勤情况，**以便**掌握学员的出勤情况。

- **验收标准**：每节课有考勤记录；支持出勤/缺席/请假三种状态；可查看学员的出勤统计；缺课学员可安排补课
- **优先级**：P1
- **关联 FR**：FR-CORE-06

## 授课教师角色

### US-TEACHER-CORE-001 — 教师工作台

**作为**：授课教师，**我希望**登录后进入教师工作台首页，**以便**了解今日课程和待办事项。

- **验收标准**：教师账号登录后进入教师工作台；工作台首页展示今日课程、待办事项、推荐资源
- **优先级**：P1
- **关联 FR**：FR-CORE-01（角色权限）

### US-TEACHER-CORE-002 — 我的课程表

**作为**：授课教师，**我希望**能查看我的课程表，**以便**了解我的授课安排。

- **验收标准**：有"我的课程表"页面；以周视图展示课程安排；课程信息包含班级、教室、时间
- **优先级**：P1
- **关联 FR**：FR-CORE-06

### US-TEACHER-CORE-003 — 班级学员管理

**作为**：授课教师，**我希望**能查看我所带班级的学员档案，**以便**了解学员情况。

- **验收标准**：在教师工作台有"我的班级"入口；可查看班级学员列表；可查看学员详细档案
- **优先级**：P1
- **关联 FR**：FR-CORE-03

### US-TEACHER-CORE-004 — 学员作品评审

**作为**：授课教师，**我希望**能查看和评审学员的项目作品，**以便**给出反馈和评分。

- **验收标准**：在教师工作台有"学生作品"入口；可查看学员上传的作品；可对作品评分和给出文字反馈
- **优先级**：P2
- **关联 FR**：FR-CORE-08

### US-TEACHER-CORE-005 — 考勤记录

**作为**：授课教师，**我希望**能记录每节课的考勤情况，**以便**掌握学员的出勤情况。

- **验收标准**：在课程详情页面有考勤记录入口；可标记每位学员的出勤状态；考勤记录保存后不可随意修改
- **优先级**：P1
- **关联 FR**：FR-CORE-06

## 财务角色

### US-FINANCE-CORE-001 — 订单管理

**作为**：财务人员，**我希望**能管理和查看所有订单，**以便**核对收入和处理退款。

- **验收标准**：可查看所有订单记录；支持按时间、学员筛选；支持导出订单列表
- **优先级**：P1
- **关联 FR**：FR-CORE-07

### US-FINANCE-CORE-002 — 退款管理

**作为**：财务人员，**我希望**能处理退款申请，**以便**及时响应客户的退款需求。

- **验收标准**：在订单详情页面有退款操作入口；支持全额退款和部分退款；退款操作需要审批；退款记录可查看
- **优先级**：P1
- **关联 FR**：FR-CORE-07

### US-FINANCE-CORE-003 — 收入统计

**作为**：财务人员，**我希望**能查看收入统计数据，**以便**了解机构的财务状况。

- **验收标准**：有收入统计仪表板；展示月度收入、年度收入；支持按课程类型、班级统计收入
- **优先级**：P1
- **关联 FR**：FR-CORE-07

### US-FINANCE-CORE-004 — 发票管理

**作为**：财务人员，**我希望**能管理发票，**以便**及时为学员开具发票。

- **验收标准**：可查看发票申请列表；支持开具电子发票；发票状态可追踪（已申请/已开具/已邮寄）
- **优先级**：P2
- **关联 FR**：FR-CORE-07

## 家长/学员角色

### US-PARENT-CORE-001 — 学习进度查看

**作为**：家长/学员，**我希望**能查看学员的学习进度，**以便**了解课时消耗和课程完成情况。

- **验收标准**：登录后可查看学员课程进度；显示剩余课时；显示已完成课程列表；显示下次上课时间
- **优先级**：P0
- **关联 FR**：FR-CORE-03

### US-PARENT-CORE-002 — 续费提醒

**作为**：家长/学员，**我希望**在课时不足时收到续费提醒，**以便**及时续费保证学习不中断。

- **验收标准**：剩余课时 ≤ 10 课时时，系统自动推送续费通知；显示续费入口和优惠信息
- **优先级**：P1
- **关联 FR**：FR-CORE-03, FR-CORE-09

### US-PARENT-CORE-003 — 作品成果查看

**作为**：家长/学员，**我希望**能查看学员的项目作品和竞赛成果，**以便**展示孩子的学习成果。

- **验收标准**：有"我的作品"展示页面；作品包含图片、描述、技术栈；作品状态（进行中/已完成）清晰标识
- **优先级**：P2
- **关联 FR**：FR-CORE-08

### US-PARENT-CORE-004 — 课程日历

**作为**：家长/学员，**我希望**能查看学员的课程日历，**以便**安排时间参加课程。

- **验收标准**：有课程日历页面；展示近期课程安排；标记上课地点和教师
- **优先级**：P1
- **关联 FR**：FR-CORE-06

### US-PARENT-CORE-005 — 接收通知

**作为**：家长/学员，**我希望**能接收系统发送的通知，**以便**及时了解重要信息。

- **验收标准**：可接收上课提醒、续费提醒、调课通知；可在站内通知中心查看所有通知；通知状态标记为已读/未读
- **优先级**：P2
- **关联 FR**：FR-CORE-09
