## 模块简介

培训平台核心功能模块定义了系统的基础业务流程和数据模型，涵盖学员管理、课程与班级管理、排课与考勤、订单与财务、作品管理等核心业务能力，是整个系统的业务基础。

## 核心功能模块总览

| 大模块 | 编号 | 说明 | 优先级 |
|--------|------|------|--------|
| 用户与角色 | FR-CORE-01 | 用户注册、登录、角色权限管理 | P0 |
| 机构管理 | FR-CORE-02 | 机构信息、机构许可证、多租户隔离 | P0 |
| 学员管理 | FR-CORE-03 | 学员档案、课程报名、课时管理、续费 | P0 |
| 教师管理 | FR-CORE-04 | 教师信息、授课安排、工作负载 | P1 |
| 课程与班级 | FR-CORE-05 | 课程产品、班级创建、课程大纲 | P0 |
| 排课与考勤 | FR-CORE-06 | 课程表、教室分配、课时消耗、补课 | P0 |
| 财务与订单 | FR-CORE-07 | 订单记录、支付、退款、发票 | P1 |
| 作品与成果 | FR-CORE-08 | 作品提交、评审、证书颁发 | P2 |
| 通知系统 | FR-CORE-09 | 站内通知、短信、邮件 | P2 |
| 数据导出 | FR-CORE-10 | 学员、课程、订单数据导出 | P2 |

## 系统架构关系

```
┌────────────────────────────────────────────────────┐
│                    前端应用层                        │
│   机构管理仪表板(DASH) · 教师工作台                │
└────────────────────────┬───────────────────────────┘
                         │ HTTPS API
                         ▼
┌────────────────────────────────────────────────────┐
│                    后端服务层                        │
│   FastAPI + WebSocket + 认证鉴权                    │
└────────────────────────┬───────────────────────────┘
                         │
        ┌────────────────┼────────────────┐
        ▼                ▼                ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│  PostgreSQL  │  │    Redis     │  │ 对象存储(OSS) │
│  业务数据    │  │  缓存/会话    │  │  文件/备份    │
└──────────────┘  └──────────────┘  └──────────────┘
```
