## 模块简介

机构管理仪表板（Institution Dashboard）是机构管理员和教务主管日常使用的核心工作界面。它聚合了机构内的关键业务指标、运营状态、快捷操作入口和 AI 驱动的智能分析，帮助管理员高效管理教学机构。

## 核心功能模块

| 模块 | 编号 | 说明 | 优先级 |
|------|------|------|--------|
| 仪表盘概览 | FR-DASH-001 | 首页展示关键指标卡、趋势图表、预警信息 | P0 |
| 学员管理 | FR-DASH-002 | 学员档案、课程报名、课时管理、续费操作 | P0 |
| 教师管理 | FR-DASH-003 | 教师信息、授课安排、工作负载统计 | P1 |
| 排课管理 | FR-DASH-004 | 课程表、教室分配、冲突检测、调课 | P0 |
| 课程与班级管理 | FR-DASH-005 | 课程创建、班级划分、课程档案 | P1 |
| 财务与订单管理 | FR-DASH-006 | 订单记录、收入统计、发票管理 | P1 |
| 作品与成果管理 | FR-DASH-007 | 学员项目作品、竞赛成果、证书颁发 | P2 |
| 机构设置 | FR-DASH-008 | 机构基本信息、权限管理、系统配置 | P1 |
| 教师工作台 | FR-DASH-009 | 教师专属工作界面、资源推荐 | P1 |
| 流失预警与留存分析 | FR-DASH-010 | AI 驱动的学员流失预警与留存策略 | P2 |
