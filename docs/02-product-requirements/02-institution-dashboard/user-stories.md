## 机构管理员角色

### US-ADMIN-DASH-001 — 总览仪表盘

**作为**机构管理员，**我希望**登录后看到机构的整体运营状况概览，**以便**快速了解学员增长、收入情况和即将到来的课程。

- **验收标准**：仪表板首页展示学员总数、在读学员数、当月新学员、当月课时消耗、当月收入等关键指标；展示近 30 天的趋势图表；展示流失预警学员和即将开课的课程
- **优先级**：P0
- **关联 FR**：FR-DASH-001

### US-ADMIN-DASH-002 — 添加新学员

**作为**机构管理员，**我希望**能快速添加新学员，**以便**将新报名的学员录入系统。

- **验收标准**：在学员管理页面有"添加学员"按钮；表单包含基本信息（姓名、性别、生日、联系方式、家长信息）；支持批量导入（Excel）；添加成功后学员出现在学员列表中
- **优先级**：P0
- **关联 FR**：FR-DASH-002

### US-ADMIN-DASH-003 — 为学员报名课程

**作为**机构管理员，**我希望**能为学员报名课程，**以便**完成学员的报名流程并分配课时。

- **验收标准**：在学员详情页面有"报名课程"入口；可选择课程、班级、课时包；自动创建订单记录；课时余额正确更新
- **优先级**：P0
- **关联 FR**：FR-DASH-002, FR-DASH-006

### US-ADMIN-DASH-004 — 管理教师信息

**作为**机构管理员，**我希望**能管理教师信息，**以便**维护教师档案和分配课程。

- **验收标准**：在教师管理页面有"添加教师"按钮；教师信息包含基本信息、联系方式、擅长课程；支持编辑和删除（非物理删除）教师
- **优先级**：P1
- **关联 FR**：FR-DASH-003

### US-ADMIN-DASH-005 — 创建和管理课程

**作为**机构管理员，**我希望**能创建和管理课程产品，**以便**提供多样的教学内容。

- **验收标准**：在课程管理页面有"添加课程"入口；课程包含名称、类型、课时数、学费、课程描述等信息；支持课程模板复用
- **优先级**：P1
- **关联 FR**：FR-DASH-005

### US-ADMIN-DASH-006 — 财务数据查看

**作为**机构管理员，**我希望**能查看财务数据和收入统计，**以便**了解机构的财务状况。

- **验收标准**：在财务管理页面可查看订单列表；支持按时间、学员筛选订单；提供月度/年度收入统计；支持导出财务报表
- **优先级**：P1
- **关联 FR**：FR-DASH-006

### US-ADMIN-DASH-007 — 系统配置管理

**作为**机构管理员，**我希望**能配置系统参数，**以便**让系统按照机构的实际情况运行。

- **验收标准**：在机构设置页面可编辑机构基本信息；可配置课时过期时间；可配置续费提醒设置；可配置机构营业时间
- **优先级**：P1
- **关联 FR**：FR-DASH-008

## 教务主管角色

### US-OPERATOR-DASH-001 — 排课管理

**作为**教务主管，**我希望**能方便地管理课程表和排课，**以便**高效安排教师和教室。

- **验收标准**：在排课管理页面可查看周视图/月视图课程表；支持拖拽调整课程时间；可分配教师和教室；自动检测时间冲突
- **优先级**：P0
- **关联 FR**：FR-DASH-004

### US-OPERATOR-DASH-002 — 调课和通知

**作为**教务主管，**我希望**能调整课程安排并自动通知相关人员，**以便**灵活应对临时变更。

- **验收标准**：在课程表中可选择课程并调整时间/教师/教室；调课后自动发送通知给相关学员和家长；调课记录可查看
- **优先级**：P1
- **关联 FR**：FR-DASH-004

### US-OPERATOR-DASH-003 — 课时消耗管理

**作为**教务主管，**我希望**能记录和管理学员的课时消耗，**以便**及时提醒续费。

- **验收标准**：在学员详情页面可查看课时余额和消耗记录；上课后课时自动扣减；课时余额不足时显示续费提醒
- **优先级**：P0
- **关联 FR**：FR-DASH-002

### US-OPERATOR-DASH-004 — 流失预警查看

**作为**教务主管，**我希望**能看到流失预警学员，**以便**及时采取措施留存学员。

- **验收标准**：在仪表板或学员管理页面有流失预警面板；展示高风险学员列表和预警原因
- **优先级**：P2
- **关联 FR**：FR-DASH-010

## 授课教师角色

### US-TEACHER-DASH-001 — 教师工作台首页

**作为**授课教师，**我希望**登录后看到我的工作台首页，**以便**了解今日课程和待办事项。

- **验收标准**：使用教师账号登录后进入教师工作台；工作台首页展示今日课程、待办事项、推荐资源
- **优先级**：P1
- **关联 FR**：FR-DASH-009

### US-TEACHER-DASH-002 — 查看我的课程表

**作为**授课教师，**我希望**能查看我的课程表，**以便**了解我的授课安排。

- **验收标准**：在教师工作台有"我的课程表"页面；以周视图展示课程安排；课程信息包含班级、教室、时间
- **优先级**：P1
- **关联 FR**：FR-DASH-009

### US-TEACHER-DASH-003 — 查看班级学员档案

**作为**授课教师，**我希望**能查看我所带班级的学员档案，**以便**了解学员情况。

- **验收标准**：在教师工作台有"我的班级"入口；可查看班级学员列表；可查看学员详细档案
- **优先级**：P1
- **关联 FR**：FR-DASH-009

### US-TEACHER-DASH-004 — 查看和评审学员作品

**作为**授课教师，**我希望**能查看和评审学员的项目作品，**以便**给出反馈和评分。

- **验收标准**：在教师工作台有"学生作品"入口；可查看学员上传的作品；可给出评分和文字反馈；支持 AI 代码审查
- **优先级**：P2
- **关联 FR**：FR-DASH-009, FR-DASH-007

### US-TEACHER-DASH-005 — 浏览教学资源

**作为**授课教师，**我希望**能浏览教学资源，**以便**为我的课程找到合适的教程和课件。

- **验收标准**：在教师工作台有"教学资源"入口；可浏览 OpenSciEd 的教程和课件；支持按类型筛选和搜索；支持收藏资源
- **优先级**：P1
- **关联 FR**：FR-DASH-009

## 财务角色

### US-FINANCE-DASH-001 — 订单管理

**作为**财务人员，**我希望**能管理和查看所有订单，**以便**核对收入和处理退款。

- **验收标准**：可查看所有订单记录；支持按时间、学员、课程类型筛选；支持导出订单列表
- **优先级**：P1
- **关联 FR**：FR-DASH-006

### US-FINANCE-DASH-002 — 退款管理

**作为**财务人员，**我希望**能处理退款申请，**以便**及时响应客户的退款需求。

- **验收标准**：在订单详情页面有退款操作入口；支持全额退款和部分退款；退款操作需要审批；退款记录可查看
- **优先级**：P1
- **关联 FR**：FR-DASH-006

### US-FINANCE-DASH-003 — 发票管理

**作为**财务人员，**我希望**能管理发票，**以便**及时为学员开具发票。

- **验收标准**：可查看发票申请；支持开具电子发票；发票状态可追踪（已申请/已开具/已邮寄）
- **优先级**：P2
- **关联 FR**：FR-DASH-006
