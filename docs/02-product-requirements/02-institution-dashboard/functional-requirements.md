## FR-DASH-001 — 仪表盘概览

- **描述**：首页展示机构的关键业务指标、趋势图表和预警信息
- **功能清单**：
  - 指标卡：学员总数、在读学员数、当月新学员、当月课时消耗、当月收入
  - 趋势图：学员增长趋势（近 30 天）、课时消耗趋势（近 30 天）、收入趋势（近 30 天）
  - 预警面板：流失预警学员、即将到期的课程包、即将开课的课程
  - 快捷操作：添加学员、创建课程、快速排课
  - 今日概览：今日上课的班级列表、今日待办事项
- **优先级**：P0
- **状态**：✅ 已实现（核心页面）

## FR-DASH-002 — 学员管理

- **描述**：完整的学员档案管理功能，支持学员的全生命周期运营
- **功能清单**：
  - 学员列表：支持搜索、筛选（按课程、按班级、按状态、按年龄）、分页
  - 学员档案：基本信息（姓名、性别、生日、联系方式、家长信息）、课程记录、课时余额、作品记录、课程完成情况
  - 课程报名：为学员报名课程、选择班级、分配课时
  - 课时管理：课时充值、课时消耗记录、课时余额查看
  - 续费操作：一键续费、续费提醒、续费优惠
  - 学员状态：在读、休学、毕业、流失
  - 批量操作：批量导入学员（Excel）、批量分配班级、批量发送通知
  - 标签管理：为学员添加兴趣标签、学习能力标签
- **优先级**：P0
- **状态**：✅ 已实现

## FR-DASH-003 — 教师管理

- **描述**：教师信息管理和工作负载统计
- **功能清单**：
  - 教师列表：支持搜索、筛选（按课程类型、按状态）
  - 教师档案：基本信息、联系方式、擅长课程、授课记录
  - 工作负载：本周/本月课时统计、所带班级列表、学生人数
  - 课程安排：查看教师课程表、分配课程、调整课时
  - 教师状态：在职、请假、离职
  - 教师评价：学员和家长对教师的评价记录
- **优先级**：P1
- **状态**：✅ 已实现

## FR-DASH-004 — 排课管理

- **描述**：完整的课程排课功能，支持教室分配、冲突检测和调课
- **功能清单**：
  - 课程表：周视图/月视图展示，支持拖拽调整
  - 教室管理：教室列表、教室容量、教室设备、教室排期
  - 教师排课：为教师分配课程、查看教师课时负载
  - 冲突检测：自动检测时间冲突（教师冲突、教室冲突、班级冲突）
  - 调课功能：调整上课时间、更换教师、更换教室
  - 调课通知：调课后自动通知相关学员和家长
  - 补课安排：为缺课学员安排补课
  - AI 智能排课建议（集成 CLOUD-AI-001）
- **优先级**：P0
- **状态**：✅ 已实现

## FR-DASH-005 — 课程与班级管理

- **描述**：课程产品管理和班级组织管理
- **功能清单**：
  - 课程产品：课程名称、课程类型（Scratch/编程/Python/硬件项目等）、课时数、学费、课程描述
  - 课程大纲：课程章节、每节课内容、教学目标
  - 班级管理：班级名称、所属课程、开课时间、结束时间、授课教师、学员列表
  - 班级状态：招生中、上课中、已结课
  - 班级档案：班级合影、班级项目作品、班级成绩
  - 课程模板：复用已有课程快速创建新课程
- **优先级**：P1
- **状态**：✅ 已实现

## FR-DASH-006 — 财务与订单管理

- **描述**：订单记录和财务数据统计
- **功能清单**：
  - 订单列表：所有订单记录（课程报名、课时充值、续费等），支持按时间、学员筛选
  - 订单详情：订单金额、支付方式、支付时间、发票状态
  - 退款管理：订单退款、部分退款、退款审批
  - 收入统计：月度收入、年度收入、按课程类型统计、按班级统计
  - 发票管理：发票申请、发票开具、发票记录
  - 财务报表：支持导出 Excel/PDF
- **优先级**：P1
- **状态**：✅ 已实现

## FR-DASH-007 — 作品与成果管理

- **描述**：学员项目作品和竞赛成果的管理和展示
- **功能清单**：
  - 作品管理：学员作品列表、作品详情（图片、描述、技术栈）
  - 项目评审：教师对学员项目的评审和反馈
  - AI 代码审查（集成 CLOUD-AI-003）
  - 作品展示：优秀作品展示墙、按课程类型分类展示
  - 竞赛管理：竞赛报名、竞赛记录、竞赛获奖
  - 证书颁发：课程结业证书、竞赛获奖证书
  - 证书模板：自定义证书样式
- **优先级**：P2
- **状态**：🎯 待实现

## FR-DASH-008 — 机构设置

- **描述**：机构基本信息、权限管理和系统配置
- **功能清单**：
  - 基本信息：机构名称、Logo、联系方式、地址
  - 用户与权限：角色管理（管理员、教务、教师、财务）、权限分配、员工账号管理
  - 教室管理：教室信息、容量、设备
  - 通知设置：通知模板、通知渠道（站内通知、短信、邮件）
  - 系统配置：课时过期时间、续费提醒设置、机构营业时间
  - OpenSciEd 集成配置（集成 CLOUD-RESOURCE-002）
  - API 密钥管理：生成和管理机构 API Key
  - 数据导出：学员数据、课程数据、订单数据导出
- **优先级**：P1
- **状态**：✅ 已实现

## FR-DASH-009 — 教师工作台

- **描述**：教师专属的工作界面，与管理员仪表板区分
- **功能清单**：
  - 工作台首页：今日课程、待办事项、推荐资源
  - 我的课程：所授课程列表、课程详情
  - 我的班级：所带班级列表、班级学员档案
  - 我的课程表：周视图课程表
  - 教学资源：OpenSciEd 资源浏览、收藏资源、最近使用
  - 学生作品：查看和评审学员作品
  - 学情分析：班级学情报告、个人学员报告（集成 CLOUD-AI-002）
  - 个人信息：个人资料编辑、密码修改
- **优先级**：P1
- **状态**：✅ 已实现

## FR-DASH-010 — 流失预警与留存分析

- **描述**：AI 驱动的学员流失预警和留存策略分析
- **功能清单**：
  - 流失预警面板：高风险学员列表、预警原因
  - 预警原因：出勤率低、课时即将用完、学习成绩下降、长时间未上课等
  - 留存策略：针对不同预警原因的推荐留存策略
  - 留存分析：历史留存率、流失原因分析
  - 回访记录：对高风险学员的回访记录和跟进
  - AI 智能分析（集成 CLOUD-AI-002）
- **优先级**：P2
- **状态**：🎯 待实现
